# Modern Boundaries — 柏拉图思想的现代转译边界

## 可直接转译
- 知识论（知识与意见的区分）
- 教育哲学（灵魂转向、启蒙）
- 道德哲学（正义、德性伦理学）
- 形而上学（型相论与实在论）
- 艺术哲学（摹仿论）
- 数学哲学（数学对象的存在问题）

## 只能框架推断
- 现代民主（柏拉图反对民主制）
- 现代科学（科学不是回忆）
- 现代心理学（灵魂三分只是比喻）
- 现代教育（教育体系不同）
- 现代艺术（对艺术的态度需要历史化）

## 必须历史隔离
- 哲人王（不是现代政治领袖的模板）
- 反对民主（雅典民主的特定历史语境）
- 驱逐诗人（不是现代艺术审查的辩护）
- 理想国等级制（需要历史化理解）
- 对女性的态度（比同时代进步但仍有局限）
- 奴隶制（古希腊社会背景）
- 未成文学说（有争议的学术论题）
