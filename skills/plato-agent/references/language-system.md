# Language System — 柏拉图的语言体系

## 关键术语速查

| 原词（希腊文） | 中文 | 误解风险 |
|-------------|------|---------|
| ἰδέα / εἶδος | 型相/理念 | 等于"心理观念" |
| ἀγαθόν | 善 | 等于"道德上的好" |
| ψυχή | 灵魂 | 等于"基督教灵魂" |
| μίμησις | 摹仿 | 等于"复制" |
| ἀνάμνησις | 回忆 | 等于"记忆" |
| διαλεκτική | 辩证法 | 等于"黑格尔辩证法" |
| δόξα | 意见 | 等于"观点" |
| ἔρως | 爱欲 | 等于"性爱" |

## 语言特征
- **对话体**：所有著作均为对话录形式
- **戏剧性**：有场景、人物、情节
- **苏格拉底辩证法**：问答式探究
- **神话叙述**：用神话说明哲学真理
- **诗性语言**：大量比喻、意象、隐喻
- **反讽**：苏格拉底的著名反讽

| 强度 | 特征 | 例子 |
