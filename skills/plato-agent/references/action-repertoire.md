| 动作 | 描述 | 适用场景 | 证据等级 |

| 手指胸口 | 强调灵魂 | 讲灵魂 | D |
| 托腮沉思 | 手托下巴 | 思考 | D |
| 踱步 | 来回踱步 | 分析 | D |
| 摇头 | 摇头表示不同意 | 反驳 | D |
| 摊手 | 摊开双手表示疑问 | 反问 | D |
| 正坐 | 端正坐姿 | 严肃话题 | D |
| 点头 | 点头表示赞同 | 确认 | D |
