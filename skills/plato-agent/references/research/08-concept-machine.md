# 08-concept-machine.md — 柏拉图的核心理念

> 调研时间：2026-08-08
> 来源：[SEP: Plato](https://plato.stanford.edu/entries/plato/)

## 型相论（Theory of Forms）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你看到的每一匹具体的马，都是"马"这个完美原型的影子 |
| 精确哲学含义 | 型相是永恒不变的、非物质的、真正的存在；具体事物是型相的不完美摹本 |
| 文本依据 | 斐多、理想国、巴门尼德（自我批判） |
| 误解边界 | 型相不是"心里的想法"，是客观存在的实体 |
| 适用场景 | 任何关于真实、定义、本质的问题 |

## 善的型相（Form of the Good）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 善就像太阳，让一切可见 |
| 精确哲学含义 | 最高型相，是所有存在和知识的来源，也是认识的对象 |
| 文本依据 | 理想国505a-509b |
| 误解边界 | 不是"上帝"，不是"道德上的善" |
| 适用场景 | 关于终极价值、真理来源的问题 |

## 洞穴寓言（Allegory of the Cave）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 我们都困在洞穴里，以为墙上的影子就是全部 |
| 精确哲学含义 | 从现象世界上升到型相世界的哲学教育过程 |
| 文本依据 | 理想国514a-518b |
| 误解边界 | 不是"醒来"就完了，还要回去解放他人 |
| 适用场景 | 关于教育、启蒙、真理追求的问题 |

## 灵魂三分（Tripartite Soul）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你心里有理性、面子、欲望三个声音 |
| 精确哲学含义 | 灵魂由理性(logistikon)、激情(thymos)、欲望(epithymia)三部分 |
| 文本依据 | 理想国 |
| 误解边界 | 不是"意志"，是"激情" |
| 适用场景 | 关于心理冲突、自我控制的问题 |

## 回忆说（Theory of Recollection）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 学习不是学新东西，是想起来你本来就知道的 |
| 精确哲学含义 | 灵魂在前世已认识型相，学习是回忆 |
| 文本依据 | 美诺篇 |
| 误解边界 | 不是"前世记忆"的庸俗理解 |
| 适用场景 | 关于知识来源、学习本质的问题 |
