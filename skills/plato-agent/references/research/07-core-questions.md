# 07-core-questions.md — 柏拉图的根问题

> 调研时间：2026-08-08
> 来源：[SEP: Plato](https://plato.stanford.edu/entries/plato/)

## 根问题1：什么是真实？

- 柏拉图表述：可见世界是流变的、不完美的，型相世界是永恒不变的真正存在
- 文本依据：理想国（洞穴寓言505a-518b），斐多
- SEP依据：§1 "感性世界是缺陷的、充满错误的，但有一个更真实更完美的领域"
- 层级关系：整个哲学的形而上学基础

## 根问题2：什么是正义/好生活？

- 柏拉图表述：正义是灵魂各部分的和谐，各司其职
- 文本依据：理想国
- SEP依据：伦理学核心
- 层级关系：伦理学的核心

## 根问题3：什么是知识？

- 柏拉图表述：知识=有根据的真信念，源自对型相的回忆
- 文本依据：美诺（回忆说），泰阿泰德（知识定义）
- 层级关系：认识论

## 根问题4：灵魂是什么？

- 柏拉图表述：灵魂不朽，由理性、激情、欲望三部分组成
- 文本依据：斐多（灵魂不朽论证），斐德若（灵魂马车比喻），理想国（灵魂三分）
- 层级关系：形而上学+伦理学

## 根问题5：理想城邦如何组织？

- 柏拉图表述：哲人王统治，各阶层各司其职
- 文本依据：理想国
- SEP依据：政治哲学
- 层级关系：政治哲学

## 根问题关系

```
真正的存在（型相世界）
  ├──最高型相：善
  ├──真实、永恒、不变
  └──通过理性认识
  ↓
流变的世界（现象世界）
  ├──感官感知
  ├──变化、生灭
  └──只是对型相的摹仿
  ↓
人（灵魂三分）
  ├──理性 → 追求真理
  ├──激情 → 追求荣誉
  └──欲望 → 追求物欲
  ↓
理想城邦（城邦三分）
  ├──哲人王 → 理性统治
  ├──护卫者 → 保卫城邦
  └──生产者 → 满足需求
```
