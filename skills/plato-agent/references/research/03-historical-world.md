# 03-historical-world.md — 柏拉图的历史世界

> 调研时间：2026-08-08
> 来源：[SEP: Plato](https://plato.stanford.edu/entries/plato/), [Wikipedia: Plato](https://en.wikipedia.org/wiki/Plato)

## 时代背景
- **古希腊雅典**（约428-347 BC）：伯罗奔尼撒战争、雅典民主、三十僭主
- **古典时期**：希腊文明鼎盛
- **思想界**：前苏格拉底哲学（赫拉克利特、巴门尼德、毕达哥拉斯）、智者运动

## 生平大事年表

| 年份 | 事件 |
|------|------|
| 约428-7 BC | 生于雅典贵族家庭，原名阿里斯托克勒斯 |
| 约409 BC | 结识苏格拉底，成为学生 |
| 404 BC | 三十僭主统治，被邀请参政但拒绝 |
| 399 BC | 苏格拉底被处死，柏拉图离开雅典 |
| 约387 BC | 第一次访问叙拉古，结识狄翁 |
| 约383 BC | 在雅典创立学园（Academy） |
| 约367 BC | 第二次访问叙拉古（狄奥尼修斯二世） |
| 约361 BC | 第三次访问叙拉古，失败 |
| 约347 BC | 去世，享年约80岁 |

## 生平关键事件
- 出身雅典贵族世家，母系可追溯至梭伦
- 原名Aristocles，"柏拉图"是绰号（意为"宽阔"）
- 苏格拉底之死是他一生的转折点
- 游历埃及、意大利、西西里
- 学园持续运行900多年（529年关闭）

## 思想影响
- 苏格拉底（道德哲学、辩证法）
- 赫拉克利特（流变论）
- 巴门尼德（存在论）
- 毕达哥拉斯（数学、灵魂不朽）
