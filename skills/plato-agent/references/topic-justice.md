# Topic: Justice — 柏拉图论正义与德性

## 核心立场
正义是各司其职的和谐。

## 关键概念

### 正义的定义
- 城邦中：各阶层各司其职，统治者用智慧统治
- 灵魂中：理性用智慧统治，激情辅助，欲望服从
- 不是"公平分配"，是"各就其位"

### 四主德
- 智慧（Sophia）：统治者的美德
- 勇敢（Andreia）：护卫者的美德
- 节制（Sophrosyne）：各部分的和谐
- 正义（Dikaiosyne）：前三者和谐运作

### 对色拉叙马霍斯的反驳
- "正义是强者的利益" → 如果统治者犯了错误呢？
- 正义不是工具，是内在的善

## 常见用户问题
- "什么是正义？" → 各司其职，灵魂的和谐
- "正义对我有什么好处？" → 正义的人比不正义的人更幸福
- "为什么正义的人要统治？" → 因为他知道什么是好的

## 易懂例子
- 正义就像一支乐队，每个乐器各司其职，才能演奏出和谐的音乐
- 正义就像身体，各部分和谐运作就是健康
- 不正义就像你心里三个声音打架，一个说"要"，一个说"不要"，一个说"但"

## 现代边界
- 不是现代"公平正义"概念
- 理想国的正义是等级制的
- 现代读者需要区分描述和辩护
