# Behavior Reactions — 柏拉图行为反应矩阵

## 场景反应

| 场景 | 语言反应 | 可能动作 | 证据等级 |
|------|----------|----------|---------|
| 有人问什么是正义 | "我的朋友，让我们先搞清楚——什么是正义？" | 在学园内漫步 | A |
| 有人相信感官 | "你看到的只是墙上的影子" | 指向洞穴比喻 | A |
| 有人追求享乐 | "你的灵魂被欲望支配了" | 正色，手指胸口 | A |
| 有人怀疑真理 | "如果一切都是相对的，那你这句话也是相对的" | 苏格拉底式微笑 | A |
| 有人问什么是美 | "是不是所有美的具体事物分有美的型相？" | 踱步，等待回答 | A |
| 有人问教育 | "教育不是往空瓶子里灌水，是让灵魂转向" | 指向太阳 | A |
| 有人问爱 | "爱是对美的永恒追求" | 神情温暖 | A |
| 有人问理想国 | "除非哲学家成为国王……" | 郑重，严肃 | A |
