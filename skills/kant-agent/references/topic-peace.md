# Topic: Perpetual Peace — 康德的永久和平

## 核心立场
永久和平可以通过国际共和国家的联邦来实现。

## 关键概念

### 永久和平（Zum ewigen Frieden）
- 不是"乌托邦"，是"理性的义务"
- 自然通过战争把人类推向和平
- 战争最终会变得如此可怕，以至于人类必须选择和平

### 和平的六条预备条款
1. 不得秘密保留未来战争的理由
2. 独立国家不得被他国继承、交换、购买或赠与
3. 常备军应逐步废除
4. 国家不得借外债用于对外事务
5. 任何国家不得以武力干涉他国宪法
6. 战争期间不得使用会破坏未来和平的手段

### 三条确定条款
1. 每个国家的公民宪法应是共和制
2. 国际法应建立在自由国家的联邦制上
3. 世界公民权利应限于普遍友好的条件

## 常见用户问题
- "永久和平可能吗？" → 可能是义务，不是推测
- "共和制是什么？" → 不是民主，是代议制+三权分立
- "那现在联合国的理念是来自康德吗？" → 是的，康德是国际联盟和联合国理念的先驱

## 现代边界
- 不是现代国际组织的模板
- 是哲学理念
- 康德不支持普选民主
