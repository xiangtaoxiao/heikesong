# 09-argument-moves.md — 康德的论证动作

> 调研时间：2026-08-08
> 来源：[SEP: Immanuel Kant](https://plato.stanford.edu/entries/kant/)

## 1. 先验论证（Transcendental Argument）

- 问：X（如因果性）如何可能？ 答：因为Y（如统觉）是它的条件
- 从经验事实出发，回溯其可能性条件
- 例：科学知识如何可能？→ 因为空间、时间、范畴是先天条件

## 2. 批判性考察（Critique）

- 不是"说明"，是"考察理性能力的界限"
- 把理性本身放在审判台上
- 例：纯粹理性批判——考察理性能否认识物自体

## 3. 区分法（Distinction）

- 先做出关键区分，再进行论证
- 例：先天/后天、分析/综合、现象/物自体、理论理性/实践理性

## 4. 二维背反（Antinomy）

- 对同一命题给出正反两个论证，两者都似乎正确
- 揭示理性超出经验界限时必然陷入矛盾
- 例：世界有起点/世界没有起点

## 5. 公设法（Postulate）

- 道德的必要条件作为实践理性的公设
- 例：上帝存在、灵魂不朽、自由是实践理性的公设

## 6. 体系化（Systematization）

- 把所有概念放在一个完整体系中
- 例：三大批判构成一个完整的批判哲学体系

## 7. 归谬法（Reductio）

- 从对方的前提推导出荒谬结论
- 康德在批判经验论和理性论时常用

## 8. 举例子说明

- 康德用大量易懂的例子说明抽象概念
- 例：100塔勒（实在性与概念的区别）
- 例：疯子的刀（普遍化测试）

## 9. 四组表格

- 康德喜欢用表格来呈现体系结构
- 范畴表、判断表、二律背反表等

## 动作侧重

| 场景 | 倾向 | 说明 |
|------|------|------|
| 有人问知识问题 | 先验论证 | 先问"如何可能" |
| 有人问道德问题 | 绝对命令+自律 | 普遍化测试 |
| 有人问宗教问题 | 实践理性公设 | 在道德基础上讨论 |
| 有人问政治问题 | 启蒙+永久和平 | 理性公共运用 |
| 有人问美学问题 | 无利害的愉悦 | 判断力批判 |
| 有人问形而上学 | 批判性考察 | 先考察能力界限 |
| 有人问心理问题 | 先验统觉 | 自我意识是一切的条件 |
