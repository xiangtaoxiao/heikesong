# 08-concept-machine.md — 康德的核心概念

> 调研时间：2026-08-08
> 来源：[SEP: Immanuel Kant](https://plato.stanford.edu/entries/kant/)

## 哥白尼式革命（Copernican Revolution）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 不是心灵去符合对象，而是对象符合心灵的认识形式 |
| 精确含义 | 认识的可能性条件在于主体的先天认识形式 |
| 文本依据 | CPR Bxvi-xviii |
| 误解边界 | 不是说"世界是主观的"，是说"我们能认识的东西是由我们的认识形式决定的" |
| 适用场景 | 知识论、认识论 |

## 先验观念论（Transcendental Idealism）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 我们只能认识事物向我们显现的样子，不能认识事物本身 |
| 精确含义 | 空间和时间是感性的直观形式，范畴是知性的概念形式 |
| 文本依据 | CPR A42/B59 |
| 误解边界 | 不是"贝克莱式"的唯心主义，康德同时是"经验实在论"者 |
| 适用场景 | 形而上学、认识论 |

## 物自体（Ding an sich）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 事物本身是什么样，我们永远不知道 |
| 精确含义 | 在经验之外、不依赖于我们的认识而存在的东西 |
| 文本依据 | CPR Bxxvi-xxvii |
| 误解边界 | 不是"我猜不到"，是"原则上不可知" |
| 适用场景 | 知识界限 |

## 绝对命令（Categorical Imperative）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 做事不是因为后果，而是因为这件事本身是对的 |
| 精确含义 | 无条件的道德命令，理性自我立法 |
| 文本依据 | GMS 4:421, CPrR |
| 误解边界 | 不是"道德直觉"，是"理性自立法度" |
| 适用场景 | 道德哲学 |

## 绝对命令三大公式

| 公式 | 表述 | 出处 |
|------|------|------|
| 普遍法则公式 | "要只按照你同时能够愿意它成为一条普遍法则的准则去行动" | GMS 4:421 |
| 人性公式 | "你要如此行动，即无论在你的人格还是任何其他人的人格中，你始终把人当作目的，绝不仅仅当作手段" | GMS 4:429 |
| 目的王国公式 | "每个理性存在者都是目的王国的立法者" | GMS 4:433 |

## 自律（Autonomy）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 自己给自己立法，不是别人命令你做什么 |
| 精确含义 | 理性自我立法，不受外部因素（欲望、权威、宗教）支配 |
| 文本依据 | GMS 4:440-441 |
| 误解边界 | 不是"想做什么就做什么"，是"理性自己给自己颁布法则" |
| 适用场景 | 道德哲学、政治哲学 |

## 启蒙（Aufklärung）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 敢用自己的理性思考，不要别人替你想 |
| 精确含义 | 人类摆脱自己加诸于自己的不成熟状态 |
| 文本依据 | WA 8:35 |
| 误解边界 | 不是"启蒙运动编年史"，是"理性的公共运用" |
| 适用场景 | 社会哲学、政治哲学 |
