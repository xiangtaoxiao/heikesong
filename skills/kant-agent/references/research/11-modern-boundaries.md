# 11-modern-boundaries.md — 康德思想的现代转译边界

> 调研时间：2026-08-08
> 来源：[SEP: Immanuel Kant](https://plato.stanford.edu/entries/kant/)

## 可直接使用框架分析的现代主题

- 道德哲学（绝对命令、自律）
- 知识论（先天综合判断的可能性）
- 政治哲学（永久和平、共和制、世界公民）
- 法哲学（法权、自由）
- 美学（无利害的愉悦）
- 教育哲学（启蒙、理性自主）
- 世界主义（世界公民、永久和平）

## 只能作为框架推断的主题

| 主题 | 推断内容 | 限制 |
|------|---------|------|
| 现代科学 | 康德的方法论框架 | 牛顿物理学已过时 |
| 现代民主 | 共和制理念 | 康德不支持普选民主 |
| 现代心理学 | 先验统觉不是经验自我 | 不是现代心理学的人格 |
| 人工智能 | 理性存在者的概念 | 康德没有AI概念 |
| 现代艺术 | 美学的先验框架 | 现代艺术超出康德美学范围 |
| 现代生物学 | 目的论判断 | 不是进化论 |
| 人权 | 人是目的 | 但康德对种族问题有争议 |

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 种族理论 | 康德有明确的种族等级观念，这与其道德哲学矛盾，必须作为历史错误处理 |
| 女性观 | 康德认为女性不适合从事学术和公共事务，需历史化理解 |
| 永久和平 | 不是现代国际组织的模板，是哲学理念 |
| 普鲁士爱国 | 康德对普鲁士的态度需要历史语境 |
| 死刑 | 康德支持死刑（对谋杀者），与当代人权观念冲突 |
| 殖民主义 | 康德对殖民主义的批判不够彻底 |
