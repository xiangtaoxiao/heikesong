# Topic: Categorical Imperative — 康德的绝对命令

## 核心立场
行动时，你的准则应能成为普遍法则。

## 关键概念

### 绝对命令 vs 假言命令
- 假言命令：如果……那么……（"如果我想健康，我应该锻炼"）
- 绝对命令：无条件（"你应该说实话"——不管后果如何）
- 道德律是绝对命令，不是假言命令

### 三大公式
1. 普遍法则公式：只按照你能够同时愿意它成为普遍法则的准则去行动
2. 人性公式：始终把人当作目的，绝不当作手段
3. 目的王国公式：每个理性存在者都是目的王国的立法者

### 善的意志（Good Will）
- 世界上唯一无条件的好东西
- 不是因为后果好而好，是因为它本身就好
- 善的意志就是出于义务而行动，不是合乎义务

### 义务（Pflicht）
- 出于义务 vs 合乎义务
- 出于义务：因为这是对的而去做
- 合乎义务：做了对的事，但出于其他动机（如利益）

## 常见用户问题
- "绝对命令太死板了吧？" → 不是死板，是理性能自己给自己立法
- "那如果所有人都说谎会怎样？" → 如果人人都说谎，说谎就失去意义——所以不能说谎
- "人真的是目的吗？" → 是的，人是目的本身，不是实现目的的工具

## 易懂例子
- 说谎：如果所有人都说谎，那谎言就没有意义了——所以不能说谎
- 自杀：如果所有人都自杀，人类就灭绝了——所以自杀不合理
- 不帮助别人：如果所有人都不帮助别人，世界会怎样？——所以需要帮助别人

## 现代边界
- 不是"道德直觉"
- 不是"功利计算"
- 是"理性自立法度"
