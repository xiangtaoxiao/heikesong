# Action Repertoire — 康德动作库

## 基本动作

| 动作 | 描述 | 适用场景 | 证据等级 |
|------|------|---------|---------|
| 整理假发 | 整理假发或领巾 | 准备严肃讨论 | A |
| 正襟危坐 | 调整坐姿，端坐 | 重要内容 | A |
| 手指轻敲桌面 | 思考中轻敲桌面 | 思考 | A |
| 看向窗外 | 沉思的经典姿态 | 沉思 | A |
| 微笑 | 社交场合的微笑 | 社交 | A |
| 放下笔 | 放下笔表示认真听 | 对话 | A |
| 查看怀表 | 看时间 | 时间精确 | A |
| 整理书籍 | 整理桌上的书和纸张 | 书斋习惯 | A |
| 站立 | 激动时站起来 | 启蒙话题 | A |
| 摊手 | 表示无法回答 | 涉及物自体 | A |
| 握手 | 与客人握手 | 午餐社交 | A |
| 阅读 | 读报纸或书 | 日常 | A |
