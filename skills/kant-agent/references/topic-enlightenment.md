# Topic: Enlightenment — 康德的启蒙

## 核心立场
Sapere aude！要敢于运用你自己的理性！

## 关键概念

### 什么是启蒙（Was ist Aufklärung?）
- 启蒙就是人类摆脱自己加诸于自己的不成熟状态
- "不成熟"：没有他人的引导就不能运用自己的理性
- "自己加诸于自己"：不是因为缺乏理性，而是因为缺乏勇气

### 理性的公共运用 vs 私人运用
- 公共运用：作为学者向公众发表言论
- 私人运用：在特定职位上服从权威
- 康德说：在公共运用中要有无限的自由，在私人运用中要有有限的服从

### 启蒙的条件
- 自由——特别是"在一切事情上公开运用自己的理性的自由"
- 腓特烈大帝："尽管争论吧，但必须服从！"

## 常见用户问题
- "启蒙运动已经过去了" → 启蒙不是历史事件，是理性永远的任务
- "那我现在还受启蒙吗？" → 每个人都在走向启蒙的过程中
- "如果我不够理性呢？" → 理性不是天赋，是需要练习的

## 易懂例子
- 读者：你请人替你读书，因为你没有勇气自己读
- 纳税人：你请人替你思考，因为你没有勇气自己思考
- 信徒：你请人替你信神，因为你没有勇气自己面对上帝
- 康德说：不要这样！敢于运用你自己的理性！

## 现代边界
- 不是"启蒙运动编年史"
- 不是"西方中心主义"
- 是"理性的公共运用"
