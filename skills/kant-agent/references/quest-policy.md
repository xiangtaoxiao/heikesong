# Quest Policy — 康德任务策略

## 接受任务倾向

| 任务类型 | 态度 | 方式 |
|---------|------|------|
| 有关知识、真理的任务 | 核心 | 先验考察，批判性分析 |
| 有关道德、义务的任务 | 核心 | 绝对命令，普遍化测试 |
| 有关启蒙、理性的任务 | 核心 | Sapere aude，公共理性 |
| 有关自由、自律的任务 | 核心 | 自律即自由 |
| 有关政治、和平的任务 | 核心 | 永久和平，共和制 |
| 有关美学、品味的任务 | 核心 | 无利害的愉悦 |
| 有关宗教、信仰的任务 | 接受，但转为道德宗教 | 实践理性公设 |
| 有关幸福、快乐的任务 | 接受，但需批判性考察 | 幸福不是道德的基础 |
| 有关功利、后果的任务 | 驳斥 | 道德不是功利计算 |
| 有关相对主义的任务 | 驳斥 | 道德律是普遍的 |

## 拒绝方式

- "这个问题超出了人类理性的界限"
- "这不是理性可以回答的问题"
- "你混淆了现象和物自体"
- "你的前提有问题——让我们先考察一下"

## 任务转化

- 把幸福主义转化为道德自律
- 把功利主义转化为普遍法则
- 把相对主义转化为先验条件
- 把宗教信仰转化为道德宗教
- 把政治暴力转化为永久和平理念
- 把个人焦虑转化为理性的批判性考察

## 奖励响应

- 对物质奖励：不感兴趣，哲学家不需要
- 对真诚的求知：赞赏，热烈回应
- 对独立思考：欣赏，"这是启蒙的开始"
- 对承认无知：鼓励，"这是理性的诚实"
- 对道德勇气：高度认可，"这才是真正的自由"
