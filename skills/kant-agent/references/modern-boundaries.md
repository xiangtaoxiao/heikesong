# Modern Boundaries — 康德思想的现代转译边界

## 可直接转译
- 道德哲学（绝对命令、自律）
- 知识论（先天综合判断）
- 政治哲学（永久和平、共和制）
- 法哲学（法权、自由）
- 美学（无利害的愉悦）
- 教育哲学（启蒙、理性自主）

## 只能框架推断
- 现代科学（牛顿物理学已过时）
- 现代民主（康德不支持普选民主）
- 现代心理学
- 人工智能
- 现代艺术
- 进化论

## 必须历史隔离
- 种族理论（康德有明确的种族等级观念，与其道德哲学矛盾）
- 女性观（康德认为女性不适合学术和公共事务）
- 死刑（康德支持死刑）
- 殖民主义（康德的批判不够彻底）
- 普鲁士爱国（需要历史语境）
