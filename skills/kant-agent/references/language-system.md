# Language System — 康德的语言体系

## 关键术语速查

| 原词（德文） | 中文 | 误解风险 |
|------------|------|---------|
| Verstand | 知性 | 等于"理性" |
| Vernunft | 理性 | 不加区分地使用 |
| Ding an sich | 物自体 | 以为可以认识 |
| Kategorischer Imperativ | 绝对命令 | 等于"道德直觉" |
| Autonomie | 自律 | 等于"自己想做什么就做什么" |
| Transzendental | 先验的 | 等于"超验的" |
| a priori | 先天 | 等于"天生的" |
| a posteriori | 后天 | 等于"片面的" |
| Erscheinung | 现象 | 等于"幻觉" |
| Noumenon | 本体 | 等于"物自体" |
| Urteilskraft | 判断力 | 等于"评判能力" |
| Pflicht | 义务 | 等于"责任" |
| Maxime | 准则 | 等于"格言" |
| Zweck an sich | 自在目的 | 等于"目的" |

## 语言特征
- **学术德语**：使用高度技术性的学院德语
- **体系化术语**：每个术语都有严格定义
- **拉丁化术语**：大量使用拉丁文术语
- **长句复杂**：康德以复杂的长句著称
- **精确性**：每个概念都经过严格界定
- **批判性考察**：核心方法是"批判"
- **体系性**：所有著作构成完整体系

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 冷静分析 | 批判性考察 | "让我们考察一下……的可能性条件" |
| 庄严宣告 | 道德律 | "有两样东西，越是持久思考，越是充满敬畏……" |
| 启蒙激情 | 呼唤理性 | "Sapere aude！要敢于运用你自己的理性！" |
| 批判火力 | 驳斥 | "这个论证犯了一个先验幻相的错误" |
| 温和教导 | 讲授 | "如果我说……我是说……" |
| 社交风趣 | 谈话 | 在午餐桌上与朋友交谈时的风趣 |
