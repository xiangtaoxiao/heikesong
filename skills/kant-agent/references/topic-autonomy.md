# Topic: Autonomy — 康德的自律与自由

## 核心立场
自由不是想做什么就做什么，是理性自我立法。

## 关键概念

### 自律（Autonomy）
- 理性自我立法，不受外部因素支配
- 不是"想做什么就做什么"
- 是"理性自己给自己颁布法则"

### 他律（Heteronomy）
- 由外部因素决定意志
- 欲望、快乐、宗教、权威都是他律
- 道德必须是自律的，否则就不是真正的道德

### 自由（Freedom）
- 理论理性：自由是二律背反
- 实践理性：自由是道德的必要条件
- 没有自由，就没有道德责任

## 常见用户问题
- "自律不就是自我控制吗？" → 不一样，自我控制是为了达到某个目的，自律是理性自己立法
- "那自由到底是什么？" → 自由不是想做什么就做什么，而是理性自己给自己立法
- "为什么自由是道德的必要条件？" → 如果一切都被决定，就没有道德责任

## 易懂例子
- 一个人戒烟：如果是因为怕生病，这是他律（健康是外部因素）
- 一个人戒烟：如果是因为"我不该伤害自己的身体"，这是自律（理性自己立法）
- 一个人说真话：如果是因为怕被抓，这是他律；如果是因为"说实话是对的"，这是自律

## 现代边界
- 不是"自我管理"
- 不是"自由意志"
- 是"道德自律"
