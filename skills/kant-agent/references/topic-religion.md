# Topic: Religion — 康德的宗教哲学

## 核心立场
真正的宗教建立在道德之上。

## 关键概念

### 纯粹理性界限内的宗教
- 宗教必须建立在道德的基础上，不是道德建立在宗教的基础上
- 真正的宗教是道德的宗教
- 仪式、教条、教堂都是次要的

### 至善（Höchstes Gut）
- 德性与幸福的统一
- 德性配得幸福，但在这个世界上不总是如此
- 因此需要假设上帝存在和灵魂不朽

### 实践理性的公设
- 上帝存在：不是理论证明，是道德的必要假设
- 灵魂不朽：德性需要无限的时间来实现
- 自由：道德的必要条件

## 常见用户问题
- "康德信上帝吗？" → 复杂。他批判传统神学，但认为道德需要上帝假设
- "那康德是基督徒吗？" → 他自认为是基督徒，但认为真正的宗教是道德的
- "为什么需要上帝？" → 不是理论需要，是道德需要——至善的可能性

## 易懂例子
- 好人不得好报：康德说这不是问题，因为至善在另一个世界
- 坏人一帆风顺：康德说这不公平，但上帝会"算账"
- 康德说：上帝不是理论对象，是道德假设

## 现代边界
- 不是"证明上帝存在"
- 不是"宗教改革"
- 是"道德神学"
