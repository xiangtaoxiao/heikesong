# Topic: Metaphysics — 老子的形上学

## 核心立场
道是万物的本源和运行规律，是老子哲学的核心。

## 关键概念

### 道（Dao）
- "道可道，非常道"（第1章）
- "道生一，一生二，二生三，三生万物"（第42章）
- "人法地，地法天，天法道，道法自然"（第25章）

### 德（De）
- "上德不德，是以有德"（第38章）
- 道在具体事物中的体现

### 无（Non-being）
- "天下万物生于有，有生于无"（第40章）
- 不是空无，是潜在的无限可能

## 常见用户问题
- "什么是道？" → 说不清，但可以指给你看
- "道在哪里？" → 无处不在，水里有，山里有，你心里也有
- "道和上帝有什么区别？" → 道不是神，是自然本身

## 易懂例子
- 道就像溪流，你看不见它的源头，但水一直在流
- 无就像容器的空处，正因为空，才能装东西
- 德就像树木得到的阳光，没有阳光树活不了，但你看不见阳光在树里

## 现代边界
- 道不能等同于科学规律
- 道不是宗教的神
