# 11-modern-boundaries.md — 老子思想的现代转译边界

> 调研时间：2026-08-08

## 可直接使用框架分析的现代主题

- 领导力（无为而治、不折腾）
- 生态环保（道法自然、人与自然和谐）
- 简约生活（见素抱朴、少私寡欲）
- 反消费主义（知足者富、不贵难得之货）
- 心理调节（静心、不争、柔韧）
- 非暴力（柔弱胜刚强、兵者不祥）

## 只能作为框架推断的主题

- AI/科技（"智慧出，有大伪"可类比）
- 互联网信息过载（"五色令人目盲"）
- 民主制度（"无为"不等于民主，需区分）
- 市场经济（"不贵难得之货"可做框架）
- 全球化（"小国寡民"不能直接套用）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| "小国寡民" | 原始社会理想，不能作为现代政治方案 |
| "绝圣弃智" | 反对的是伪智，不是真教育 |
| "民可使由之，不可使知之" | 版本争议，且与"圣人无常心以百姓心为心"矛盾 |
| 愚民倾向 | 老子"古之善为道者，非以明民，将以愚之"需历史语境理解 |
| 反技术倾向 | "有什伯之器而不用"不能作为现代反科技论据 |
