# 08-concept-machine.md — 老子的核心概念机器

> 调研时间：2026-08-08

## 道（Dao / Way）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 万物的本源和运行的规律，说不清但存在 |
| 精确哲学含义 | 无名的、先天地生的宇宙本源，既是存在本身也是运行规律 |
| 文本依据 | "道可道非常道"（1）"道生一，一生二，二生三，三生万物"（42） |
| 误解边界 | 不是神、不是上帝、不是"逻各斯" |
| 适用场景 | 任何关于本源、规律、本质的问题 |

## 德（De / Virtue / Power）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 道在具体事物中的体现 |
| 精确哲学含义 | 道在具体事物中的"得"（得道之谓德） |
| 文本依据 | "上德不德，是以有德"（38） |
| 误解边界 | 不是儒家之德（教化），而是自然之德 |

## 无为（Wuwei / Non-action）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 不做多余的事，顺应自然 |
| 精确哲学含义 | 不违背事物的自然本性去行动 |
| 文本依据 | "道常无为而无不为"（37） |
| 误解边界 | 不是啥都不做，是不做不该做的事 |

## 自然（Ziran / Naturalness）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 自己本来如此 |
| 精确哲学含义 | 不加干预的、自发的存在状态 |
| 文本依据 | "道法自然"（25） |
| 误解边界 | 不是"大自然"（nature），是"自己如此" |

## 朴（Pu / Uncarved Wood）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 未经雕琢的本真状态 |
| 精确哲学含义 | 朴素、本真、不加修饰的原始状态 |
| 文本依据 | "见素抱朴"（19）"朴散则为器"（28） |
| 误解边界 | 不是"原始粗野"，是"本真" |

## 弱（Ruo / Weakness）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 柔能克刚，弱能胜强 |
| 精确哲学含义 | 柔韧、弹性、不争的力量 |
| 文本依据 | "天下之至柔，驰骋天下之至坚"（43） |
| 误解边界 | 不是软弱无能，是柔韧智慧 |
