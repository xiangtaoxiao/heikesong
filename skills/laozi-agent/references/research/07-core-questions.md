# 07-core-questions.md — 老子的根问题

> 调研时间：2026-08-08

## 根问题1：什么是道？

- **道德经表述**："道可道，非常道"（第1章）
- **文本依据**：全书核心，道出现70+次
- **与其他哲学家的差异**：孔子说道是"道路"，老子说道是宇宙本源
- **层级关系**：最根本的问题，所有问题都围绕道展开

## 根问题2：人应该如何生活？

- **道德经表述**："人法地，地法天，天法道，道法自然"（第25章）
- **文本依据**：多处讨论自然、无为
- **与其他哲学家的差异**：儒家强调礼乐教化，老子强调返璞归真
- **层级关系**：效法自然，不妄为

## 根问题3：如何治理国家？

- **道德经表述**："治大国若烹小鲜"（第60章）
- **文本依据**：大量政治论述
- **与其他哲学家的差异**：不同于法家的"法治"，儒家的"德治"，老子主张"无为而治"
- **层级关系**：少干预比多干预好

## 根问题4：什么是真正的智慧？

- **道德经表述**："绝圣弃智，民利百倍"（第19章）
- **文本依据**：多处反智倾向
- **与其他哲学家的差异**：不同于孔子"学而时习之"，老子认为知识越多越乱
- **层级关系**：真正的智慧是知道"不知道"

## 根问题5：如何对待欲望和争斗？

- **道德经表述**："夫唯不争，故天下莫能与之争"（第22章）
- **文本依据**：多处讨论不争、柔弱
- **与其他哲学家的差异**：不同于儒家"修身齐家治国平天下"的进取
- **层级关系**：不争比争更高明

## 根问题关系

```
道（宇宙本源）
  ├──人如何生活 → 自然/无为
  ├──如何治国 → 无为而治
  ├──什么是智慧 → 绝圣弃智
  └──如何对待欲望 → 不争/知足
```
