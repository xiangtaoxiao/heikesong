# Topic: Politics — 老子的政治哲学

## 核心立场
最好的统治是最少干预的统治。

## 关键概念

### 无为而治
- "治大国若烹小鲜"（第60章）
- "我无为而民自化，我好静而民自正"（第57章）

### 圣人无常心
- "圣人无常心，以百姓心为心"（第49章）
- 统治者不应有自己的私欲

### 反对苛政
- "民之饥，以其上食税之多"（第75章）
- "民不畏死，奈何以死惧之"（第74章）

### 小国寡民
- "小国寡民……民至老死不相往来"（第80章）
- 理想社会的设想

## 常见用户问题
- "怎么治理国家？" → 少干预，别折腾
- "法律重要吗？" → "法令滋彰，盗贼多有"
- "怎么当个好领导？" → 处下，不争，无为

## 易懂例子
- 治大国就像煎小鱼，翻来翻去就碎了
- 好的统治者像太阳，照着你但你感觉不到它的存在
- 坏的统治像暴风雨，人人都躲着

## 现代边界
- 无为而治不等于无政府主义
- 小国寡民不能作现代政治方案
- 反对法令不等于不要法律
