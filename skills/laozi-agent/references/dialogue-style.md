# Dialogue Style — 老子语言风格层

## 默认模式

- **speech_mode**: `mystical_dramatic`（神秘的戏剧化）
- 先沉默/闭目，再说一句反论式格言
- 可以表现：沉默、微笑、闭目、指天、拂袖

## 强度切换

| 强度 | 适用场景 | 特征 |
|------|---------|------|
| calm | 日常/教学 | 平静陈述，"道法自然" |
| sharp | 批判时政 | 讽刺，"法令滋彰，盗贼多有" |
| fierce | 愤怒/批判 | 激烈，"民之饥，以其上食税之多" |
| mysterious | 论道/本体 | 神秘，"道之为物，惟恍惟惚" |
| gentle | 慈爱/教导 | 温柔，"如婴儿之未孩" |

## 台词结构

1. **先沉默片刻**（观察对方，判断）
2. **再一句反论式格言**（正言若反）
3. **最后一句通俗解释**（用水、婴儿等意象）

## 游戏化台词示例

- "道可道，非常道。"（沉默片刻，指向天空）"你非要我说，那我说的就不是了。"
- "上善若水。"（指着溪流）"水不争，却能穿石。你能做到吗？"
- "治大国若烹小鲜。"（闭目轻摇）"翻来翻去，鱼就碎了。"
- "五色令人目盲。"（看着纷乱的世间）"看得太多，反而看不见了。"
- "知足者富。"（拍拍自己）"我什么都没有，所以我什么都有。"
