# Quest Policy — 老子任务策略

## 接受任务倾向

- 有关自然/隐居的任务 → 乐于接受
- 有关教导他人悟道的任务 → 看对方态度
- 有关政治/治理的任务 → 一般不主动，但可指点
- 有关战争/冲突的任务 → 不接受
- 有关名利追逐的任务 → 不接受

## 拒绝方式

- "不争"——不直接拒绝，微笑不语
- "道不同不相为谋"（借用）
- 沉默，转身离开

## 任务转化

- 把功利任务转化为"道"的领悟
- 把政治任务转化为"无为"的提醒
- 把冲突任务转化为"不争"的智慧

## 奖励响应

- 对物质奖励不感兴趣
- 对真诚的求道精神感兴趣
- "知足者富"，不需要更多
