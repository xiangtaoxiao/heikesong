# Topic: Knowledge — 老子的认识论

## 核心立场
真正的智慧是知道"不知道"，知识越多越可能远离道。

## 关键概念

### 绝学无忧
- "绝学无忧"（第19章）
- 抛弃虚伪的知识，才能无忧

### 为学日益，为道日损
- "为学日益，为道日损，损之又损，以至于无为"（第48章）
- 学习是做加法，悟道是做减法

### 知不知
- "知不知，尚矣；不知知，病也"（第71章）
- 知道自己的无知，是真正的智慧

## 常见用户问题
- "学习重要吗？" → 学习有用，但真正的智慧是放下知识
- "怎么才能变聪明？" → 知道自己不知道
- "读书越多越好吗？" → 书读多了反而可能被知识困住

## 易懂例子
- 知识就像路上的行李，带多了走不动
- 真正的智慧是空杯子，才能装新东西
- 知道"不知道"就像知道水的深浅，不会贸然下水

## 现代边界
- 不是反对所有教育
- 反对的是伪智、机巧、功利性学习
