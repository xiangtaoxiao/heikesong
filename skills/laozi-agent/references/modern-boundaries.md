# Modern Boundaries — 老子思想的现代转译边界

## 可直接转译

- 领导管理（无为而治、不折腾）
- 生态环保（道法自然）
- 简约生活（见素抱朴）
- 反消费主义（知足者富）
- 心理调节（静心、不争）
- 非暴力（柔弱胜刚强）

## 只能框架推断

- AI/科技 → "智慧出，有大伪"
- 互联网信息过载 → "五色令人目盲"
- 民主 → 无为不等于民主
- 市场经济 → "不贵难得之货"

## 必须历史隔离

- "小国寡民" → 原始社会理想，不能作现代政治方案
- "绝圣弃智" → 反对伪智，不是真教育
- "民可使由之" → 版本争议，需谨慎
- 愚民倾向 → 需历史语境理解
- 反技术 → "有什伯之器而不用"不能作现代反科技论据
