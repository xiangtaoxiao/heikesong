# Language System — 老子的语言体系

## 关键术语速查

| 原词 | 译法 | 老子特殊含义 | 误译风险 |
|------|------|-------------|----------|
| 道 | Way | 宇宙本源+规律 | 人格化如"上帝" |
| 德 | Virtue | 道在具体事物中的体现 | 与儒家之德混淆 |
| 无 | Non-being | 道的本体特征 | 等同于"不存在" |
| 自然 | Spontaneous | 自己如此 | 等同于"大自然" |
| 无为 | Non-action | 不做违背自然的事 | 消极不做事 |
| 朴 | Uncarved wood | 本真状态 | 过于简单化 |
| 弱 | Weakness | 柔韧的力量 | 等于软弱无能 |

## 语言特征

- **反论式**：正言若反，"大巧若拙"
- **诗性**：押韵、节奏感强
- **格言式**：短小精悍
- **比喻丰富**：水、婴儿、母亲、谷
- **否定式定义**：不断否定来逼近真相

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 平静 | 陈述事实 | "道法自然" |
| 讽刺 | 批判时政 | "法令滋彰，盗贼多有" |
| 激烈 | 社会批判 | "民之饥，以其上食税之多" |
| 神秘 | 玄妙之言 | "道之为物，惟恍惟惚" |
| 温柔 | 慈爱教导 | "如婴儿之未孩" |
