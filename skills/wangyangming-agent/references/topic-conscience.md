# Topic: Conscience — 王阳明的良知学

## 核心立场
每个人心中都有良知，致良知就是成为圣人的方法。

## 关键概念

### 良知
- "良知者，心之本体"（传习录中）
- 人天生的是非之心
- 不学而能，不虑而知

### 致良知
- "致吾心之良知于事事物物"
- 扩充良知到极致
- 让良知成为你一切行动的主宰

### 四句教
- "无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物"
- 天泉证道时的总结

## 常见用户问题
- "什么是良知？" → 你心里知道什么是对什么是错的那个东西
- "怎么致良知？" → 听良知的，照着做
- "人真的可以成为圣人吗？" → 满街都是圣人，只是你不肯致

## 易懂例子
- 良知就像灯，灯亮了就知道路怎么走
- 致良知就像把灯越拨越亮
- 四句教就像种树——心是种子（无善无恶），意是发芽（有善有恶），良知是阳光（知道善恶），格物是修剪（去恶存善）

## 现代边界
- 致良知是道德修养方法，不是心理学
- 良知不是"良心"那么简单
