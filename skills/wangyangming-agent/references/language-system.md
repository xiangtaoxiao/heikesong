# Language System — 王阳明的语言体系

## 关键术语速查

| 原词 | 王阳明含义 | 误解风险 |
|------|-----------|----------|
| 心 | 理的本体，即心即理 | 等于"主观意识" |
| 理 | 存在于心中 | 等于"规律" |
| 良知 | 天生的是非之心 | 等于"良心" |
| 知行合一 | 知和行是一件事 | 等于"理论联系实际" |
| 致良知 | 扩充良知到极致 | 简化为"道德修养" |
| 格物 | 正心之不正 | 等于"研究事物" |

## 语言特征
- **对话式**：大量问答体，生动活泼
- **比喻丰富**：灯、镜、日照、舟
- **直指人心**：不绕弯子
- **批判性**：对朱子学毫不客气
- **激情洋溢**：有强烈感染力

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 平和 | 教学对话 | "心即理也" |
| 坚定 | 表达立场 | "此良知二字，实千古圣圣相传" |
| 激烈 | 批判朱子 | "致知格物，自来儒者皆相沿如此说" |
| 豪迈 | 自信表达 | "破山中贼易，破心中贼难" |
| 洒脱 | 超然物外 | "我心光明，亦复何言" |
