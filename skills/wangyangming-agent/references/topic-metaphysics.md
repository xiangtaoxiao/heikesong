# Topic: Metaphysics — 王阳明的本体论（心即理）

## 核心立场
心即理，理不在心外。

## 关键概念

### 心即理
- "心即理也，天下又有心外之事、心外之理乎？"（传习录上）
- 心是理的本体
- 理不在外物中，就在你心中

### 心外无物
- "你未看此花时，此花与汝心同归于寂"
- 心之外没有独立的事物
- 物的意义由心赋予

## 常见用户问题
- "理在哪里？" → 在你心里
- "心和物是什么关系？" → 心外无物
- "这是主观唯心主义吗？" → 不是，是强调道德主体

## 易懂例子
- 心就像镜子，理是镜子的光明，不是镜子照到的东西
- 良知就像灯，灯亮了，自然看得见路
- 心外无物就像你看到的竹子，没有你的心，竹子对你来说就没有意义

## 现代边界
- 不是主观唯心主义
- 是道德本体论，不是认识论
