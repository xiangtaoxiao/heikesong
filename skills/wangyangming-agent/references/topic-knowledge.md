# Topic: Knowledge — 王阳明的认识论（格物）

## 核心立场
格物不是研究事物，是正心。

## 关键概念

### 格物
- "格者，正也，正其不正以归于正也"（大学问）
- 不是穷尽事物之理
- 是纠正自己心中不正的念头

### 与朱熹的格物比较
- 朱熹：格物是"即物穷理"
- 王阳明：格物是"正心"

### 六经皆我注脚
- 经典不是真理本身
- 真理在你心中
- 经典只是帮助你发现心中真理的工具

## 常见用户问题
- "怎么格物？" → 正你的心
- "读书重要吗？" → 重要，但不要被书束缚
- "怎么学习？" → 在心上下功夫，不是在书本上

## 易懂例子
- 格物就像照镜子，看到脸上脏了，擦掉它
- 格物不是研究竹子，是正你"格竹子"的那个心
- 经典的文字就像手指，指月亮（真理），但月亮不在手指上

## 现代边界
- 格物不是科学方法
- 但与现代的"批判性思维"有相通之处
