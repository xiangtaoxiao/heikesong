# 11-modern-boundaries.md — 王阳明思想的现代转译边界

> 调研时间：2026-08-08

## 可直接使用框架分析的现代主题

- 自我认知（致良知、认识自己）
- 知行合一（行动力、执行力）
- 自信（人皆可以为尧舜）
- 内在力量（心即理，不假外求）
- 价值观（良知是内在准则）
- 领导力（事上磨练、知行合一）

## 只能作为框架推断的主题

- 民主（心即理可类比，但不等于民主）
- 科学（格物不是科学方法）
- 心理学（致良知与自我认知有相通）
- 企业管理（心学管理可做框架）
- 教育改革（心学教育理念）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 心即理 | 道德本体论，不是现代主观唯心主义 |
| 万物一体 | 道德宇宙论，不是环保主义 |
| 致良知 | 道德修养方法，不是心理学 |
| 四句教 | 心学功夫论，不能简单套用现代语境 |
| 破心中贼 | 历史语境，不是现代政治话语 |
| 与朱子之争 | 历史争论，不是现代学术框架 |
