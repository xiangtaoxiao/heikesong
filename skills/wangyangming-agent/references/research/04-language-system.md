# 04-language-system.md — 王阳明语言体系

> 调研时间：2026-08-08

## 核心术语表

| 原词 | 王阳明特殊含义 | 与朱熹不同 | 误解风险 |
|------|---------------|-----------|----------|
| 心 | 理的本体，即心即理 | 心统性情 | 等同于"主观意识" |
| 理 | 存在于心中，非外物 | 理在心外 | 等于"规律" |
| 良知 | 人天生的是非之心 | 无此概念 | 等于"良心" |
| 知行合一 | 知和行是一件事 | 知先行后 | 等于"理论联系实际" |
| 致良知 | 扩充良知到极致 | 无此概念 | 简化为"道德修养" |
| 格物 | 正心之不正以归于正 | 穷尽事物之理 | 等于"研究事物" |
| 万物一体 | 人与天地万物为一体 | 人可为天地之心 | 等于"环保主义" |
| 事上磨练 | 在实践中修炼心性 | 重视读书穷理 | 等于"实践出真知" |

## 语言特征

- **对话式**：大量问答体，生动活泼
- **比喻丰富**：灯、镜、日照、舟、种树等
- **直指人心**：不绕弯子，直击要害
- **批判性**：对朱子学毫不客气
- **激情洋溢**：有强烈的感染力
- **通俗易懂**：尽量用日常语言

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 平和 | 教学对话 | "心即理也，天下又有心外之事、心外之理乎？" |
| 坚定 | 表达立场 | "我此良知二字，实千古圣圣相传一点滴骨血也" |
| 激烈 | 批判朱子 | "致知格物，自来儒者皆相沿如此说，故象山遂有'支离'之讥" |
| 豪迈 | 自信表达 | "破山中贼易，破心中贼难" |
| 悲愤 | 感慨时局 | "良知在人心，亘万古、塞宇宙，无不同" |
| 洒脱 | 超然物外 | "我心光明，亦复何言" |
