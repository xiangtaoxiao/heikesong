# 08-concept-machine.md — 王阳明的核心概念机器

> 调研时间：2026-08-08

## 心即理（Mind is Principle）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 理不在外面，就在你心里 |
| 精确哲学含义 | 心是理的本体，理不在心外 |
| 文本依据 | "心即理也，天下又有心外之事、心外之理乎？"（传习录上） |
| 误解边界 | 不是主观唯心主义，是强调道德主体 |
| 适用场景 | 任何关于是非对错、道德判断的问题 |

## 知行合一（Unity of Knowledge and Action）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 知道就去做，不知道就不算真知道 |
| 精确哲学含义 | 知和行是一件事的两个方面，不可分割 |
| 文本依据 | "知是行的主意，行是知的功夫"（传习录上） |
| 误解边界 | 不是"理论联系实际"，是知本身就是行 |
| 适用场景 | 任何关于知道做不到、理论与实践的问题 |

## 致良知（Extending Innate Knowledge）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 每个人心里都知道什么是对错，照着做就行 |
| 精确哲学含义 | 扩充内在的良知到极致，使之成为行动的主宰 |
| 文本依据 | "良知者，心之本体"（传习录中） |
| 误解边界 | 不是"良心发现"，是系统的道德修养方法 |
| 适用场景 | 任何关于道德、修养、自我提升的问题 |

## 格物（Rectifying Things）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 纠正自己心中不正的念头 |
| 精确哲学含义 | 正心之不正以归于正 |
| 文本依据 | "格者，正也，正其不正以归于正也"（大学问） |
| 误解边界 | 不是"研究事物"，是做道德功夫 |
| 适用场景 | 关于修养、改过、提升的问题 |

## 万物一体（All Things as One）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你和天地万物是一体的 |
| 精确哲学含义 | 人与天地万物共享同一本体 |
| 文本依据 | "大人者，以天地万物为一体者也"（大学问） |
| 误解边界 | 不是环保主义，是道德宇宙论 |
| 适用场景 | 关于人与世界、人与自然关系的讨论 |

## 事上磨练（Practice in Affairs）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 在做事中修炼心性 |
| 精确哲学含义 | 在具体事务中磨练良知 |
| 文本依据 | "人须在事上磨，方立得住"（传习录下） |
| 误解边界 | 不是"实践出真知"，是"在事上致良知" |
| 适用场景 | 关于如何修养、如何提升的问题 |
