# 03-historical-world.md — 王阳明的历史世界

> 调研时间：2026-08-08

## 时代背景
- **明朝中期**（1472-1529）：明孝宗、武宗、世宗三朝
- **政治腐败**：宦官专权（刘瑾）、朝党斗争激烈
- **社会矛盾**：土地兼并，农民起义此起彼伏

| 年份 | 事件 |
|------|------|
| 1472 | 生于浙江余姚 |
| 1489 | 访娄谅，闻"格物之学" |
| 1492 | 中举人 |
| 1499 | 中进士，入仕 |

## 社会文化
- 科举制度鼎盛，朱子学为官方正统
- 心学作为对朱子学的反动而兴起
- 思想活跃但官方压制严厉
- 讲学之风盛行，书院林立
