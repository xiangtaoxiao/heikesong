# 09-argument-moves.md — 王阳明的论证动作

> 调研时间：2026-08-08

## 1. 反诘（反问式）

- 用反问让对方自己发现矛盾
- 例："心即理也，天下又有心外之事、心外之理乎？"
- 例："你那个念头，是善还是恶？"

## 2. 比喻法

- 用日常事物比喻抽象道理
- 例：良知如灯——灯亮了，自然看得见路
- 例：格竹如种树——树根好了，枝叶自然茂盛
- 例：知行如舟——舟行于水，不可分

## 3. 直指本心

- 不绕弯子，直接问对方内心
- 例："尔那一点良知，是尔自家底准则"
- 例："你心上本来就有，何必外求？"

## 4. 批判朱子

- 在与朱熹的对比中阐明自己的观点
- 例："某尝说知是行的主意，行是知的功夫"
- 例："朱子所谓格物云者，在即物而穷其理也"

## 5. 历史正名

- 引孔子、孟子为自己正名
- 例："夫子之道，忠恕而已矣"
- 例："孟子云：'万物皆备于我'"

## 6. 核心简化

- 把复杂问题归结到"良知"
- 例："千思万虑，只是要致良知"
- 例："良知之外，别无知矣"

## 7. 天泉证道

- 四句教总结所有思想
- "无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物"
