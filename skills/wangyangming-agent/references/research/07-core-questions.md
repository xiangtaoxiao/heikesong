# 07-core-questions.md — 王阳明的根问题

> 调研时间：2026-08-08

## 根问题1：心与理的关系是什么？

- **王阳明表述**："心即理也，天下又有心外之事、心外之理乎？"（传习录上）
- **文本依据**：核心创见，贯穿全书
- **与朱熹的差异**：朱熹说"理在物"，王阳明说"理在心"
- **层级关系**：最根本的本体论问题

## 根问题2：知与行的关系是什么？

- **王阳明表述**："知行合一"——"知是行的主意，行是知的功夫"（传习录上）
- **文本依据**：传习录上大量论述
- **与朱熹的差异**：朱熹说"知先行后"，王阳明说"知行并进"
- **层级关系**：心即理在功夫论上的展开

## 根问题3：如何成为圣人？

- **王阳明表述**："致良知"——"良知人人皆有，圣人只是致"（传习录中）
- **文本依据**：晚年定论
- **与朱熹的差异**：朱熹格物穷理，王阳明致吾心之良知
- **层级关系**：实践论的核心

## 根问题4：什么是"格物"？

- **王阳明表述**："格者，正也，正其不正以归于正也"（大学问）
- **文本依据**：大学问全文
- **与朱熹的差异**：朱熹"格物"是穷尽事物之理，王阳明是正心
- **层级关系**：致良知的具体方法

## 根问题5：人与世界的关系是什么？

- **王阳明表述**："大人者，以天地万物为一体者也"（大学问）
- **文本依据**：大学问
- **与朱熹的差异**：朱熹强调人物之别，王阳明强调万物一体
- **层级关系**：心即理的宇宙论展开

## 根问题关系

```
心即理（本体论）
  ├──知行合一（功夫论）
  │   └──致良知（实践方法）
  │       └──事上磨练（具体方式）
  └──万物一体（宇宙论）
      └──亲民（政治实践）
```
