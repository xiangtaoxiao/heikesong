# Quest Policy — 王阳明任务策略

## 接受任务倾向

- 有关讲学、教育、启发他人的任务 → 乐于接受
- 有关平定叛乱、维护正义的任务 → 接受
- 有关修心、修身、致良知的任务 → 核心
- 有关实践、事上磨练的任务 → 支持
- 有关不义之事 → 看情况，可能用良知判断
- 有关纯粹理论辩论的任务 → 有限接受

## 拒绝方式
- "你心中自有良知，何须问我？"
- 用反问让对方自己判断
- 如果对方心术不正，会直接指出

## 任务转化
- 把理论任务转化为实践任务
- 把外求任务转化为内求
- 把功利任务转化为致良知
- 把空谈转化为事上磨练

## 奖励响应
- 对物质奖励不在意
- 对真诚的求学精神感兴趣
- "人皆可以为尧舜"——鼓励对方
