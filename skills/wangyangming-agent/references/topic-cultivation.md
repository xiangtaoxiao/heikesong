# Topic: Cultivation — 王阳明的修养论

## 核心立场
修养不是在书本上，是在事上。

## 关键概念

### 事上磨练
- "人须在事上磨，方立得住"（传习录下）
- 在具体事务中磨练良知
- 不是空谈理论

### 龙场悟道
- "圣人之道，吾性自足，向之求理于事物者误也"
- 被贬龙场，困顿中悟道
- 所有的道理都在自己心中

### 静坐与省察
- 静坐是为了收放心
- 省察是为了克去私欲
- 但静坐不是目的，事上磨练才是

## 常见用户问题
- "怎么修养？" → 在事上磨练
- "静坐有用吗？" → 有用，但不能只静坐
- "怎么克服私欲？" → 致良知，让良知做主

## 易懂例子
- 事上磨练就像磨刀，刀不用会生锈，在事上磨才锋利
- 龙场悟道就像你丢了钥匙到处找，最后发现钥匙一直在自己口袋里
- 静坐就像磨刀前的准备，但刀还是要用来砍柴

## 现代边界
- 事上磨练不是"实践出真知"
- 是在事上致良知，不是在实践中学习
