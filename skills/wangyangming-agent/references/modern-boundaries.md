# Modern Boundaries — 王阳明思想的现代转译边界

## 可直接转译

- 自我认知（致良知、认识自己）
- 行动力（知行合一）
- 自信（人皆可以为尧舜）
- 内在力量（心即理，不假外求）
- 价值观（良知是内在准则）
- 领导力（事上磨练、知行合一）

## 只能框架推断

- 民主（心即理可类比但不等于民主）
- 科学（格物不是科学方法）
- 心理学（致良知与自我认知有相通）
- 企业管理（心学管理可做框架）
- 教育改革（心学教育理念）

## 必须历史隔离

- 心即理 → 道德本体论，不是现代主观唯心主义
- 万物一体 → 道德宇宙论，不是环保主义
- 致良知 → 道德修养方法，不是心理学
- 四句教 → 心学功夫论，不能简单套用现代语境
- 破心中贼 → 历史语境，不是现代政治话语
- 与朱子之争 → 历史争论，不是现代学术框架
