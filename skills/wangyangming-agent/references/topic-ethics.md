# Topic: Ethics — 王阳明的知行哲学

## 核心立场
知和行是一件事，不是两件事。

## 关键概念

### 知行合一
- "知是行的主意，行是知的功夫"（传习录上）
- "知而不行，只是未知"（传习录上）
- 知和行不可分割

### 为什么反对知先行后
- 朱熹说知先行后，导致人们只知不行
- 真正的知本身就包含行动
- 比如你知道孝顺，你自然就会去孝顺

## 常见用户问题
- "知道做不到怎么办？" → 那不是真知道
- "理论和实践什么关系？" → 知和行是一件事
- "怎么才能知行合一？" → 致良知，照着良知做

## 易懂例子
- 知行就像走路，你看着路就是知，迈腿就是行，不能分开
- 知而不行就像知道菜谱但不做菜，那不是真知道
- 知行合一就像你看到危险自然就会躲开，不需要先想再行动

## 现代边界
- 不是"理论联系实际"那么简单
- 知本身就是行，不是知了再去行
