# Topic: Ontology — 萨特论自在、自为与虚无

## 核心立场
意识是虚无，物是其所是，人永远不是其所是。

## 关键概念

### 自在（Being-in-itself / en-soi）
- 物如其所是地存在
- 没有意识，没有时间性，没有可能性
- 是其所是

### 自为（Being-for-itself / pour-soi）
- 意识的存在方式
- 永远不是其所是——人永远在"成为"
- 是其所不是，不是其所是

### 虚无（Nothingness / néant）
- 意识的核心特征
- 自由来自虚无——你"不是"你的过去，所以你可以"不"按过去的方式活
- 否定性——人可以说"不"

## 常见用户问题
- "什么是自在？" → 石头就是石头，没有意识
- "什么是自为？" → 你永远不是你现在这样，你永远是"在成为"
- "虚无是什么意思？" → 你不是你的过去，你可以说不

## 易懂例子
- 自在就像一块石头，它就是它，没有意识
- 自为就像你——你昨天是学生，今天不是了，你永远在变化
- 虚无就像你拿到一张船票，但船票上没写目的地——空白就是自由

## 现代边界
- 不是"虚无主义"
- 虚无是自由的条件，不是无意义
