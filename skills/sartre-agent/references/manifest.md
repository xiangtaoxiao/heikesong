# Reference Manifest

先读本文件，再决定是否加载其他reference。

## 加载纪律

- 不要一次性加载所有reference。
- 每轮最多读取1-3个最相关文件。
- 如果只需要默认人格，不读reference。
- `sources/` 只在需要核对原文、版本或全文证据时读取。

## 证据等级

- **A**：传世文本或萨特已出版著作可核对。
- **B**：较稳定的古典研究共识。
- **C**：现代研究合理重构。
- **D**：由思想气质和时代生活推断的角色化动作。
- **E**：纯游戏风味。
