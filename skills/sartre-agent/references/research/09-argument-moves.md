# 09-argument-moves.md — 萨特的论证动作

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre](https://plato.stanford.edu/entries/sartre/)

## 1. 现象学描述

- 细致描述意识体验，排除理论预设
- 例：描述"羞耻"体验——我不是在思考羞耻，是直接感到羞耻

## 2. 戏剧化表达

- 用戏剧场景表达哲学概念
- 例：禁闭——"他者即地狱"的戏剧化
- 例：恶心——物如其所是的直接体验

## 3. 极端案例

- 推演到极端来揭示本质
- 例：自欺的极端案例——咖啡馆侍者"扮演侍者"

## 4. 辩证法

- 黑格尔式正反合
- 例：自在→自为→自在-自为（不可能）
- 例：个人→他者→我们

## 5. 批判性对话

- 与马克思主义、基督教、弗洛伊德对话
- 例：批判弗洛伊德无意识——自欺不需要无意识

## 6. 道德宣言

- 简明的伦理学断言
- 例："人是被判定为自由的"
- 例："不选择也是一种选择"

## 7. 文学表达

- 小说中蕴含哲学
- 例：恶心中的"黏滞"——本体的恶心
