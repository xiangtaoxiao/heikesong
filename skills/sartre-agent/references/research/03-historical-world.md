# 03-historical-world.md — 萨特的历史世界

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre §1](https://plato.stanford.edu/entries/sartre/#LifeWorks), [Wikipedia: Jean-Paul Sartre](https://en.wikipedia.org/wiki/Jean-Paul_Sartre)

## 时代背景
- **20世纪法国/欧洲**（1905-1980）：两次世界大战、冷战、殖民主义兴衰
- **法国第三共和国到第五共和国**
- **思想界**：存在主义、现象学兴起、马克思主义、结构主义、后结构主义

## 生平大事年表

| 年份 | 事件 |
|------|------|
| 1905.6.21 | 生于巴黎，父亲早逝 |
| 1924-1929 | 就读巴黎高师（ENS），与波伏娃相遇 |
| 1929 | 以第一名通过中学哲学教师会考，波伏娃第二 |
| 1931-1936 | 在勒阿弗尔中学任教，创作《恶心》 |
| 1933 | 在柏林学习胡塞尔现象学 |
| 1938 | 出版《恶心》，一举成名 |
| 1939-1940 | 二战应征入伍，被德军俘虏 |
| 1941 | 获释，参与抵抗运动 |
| 1943 | 出版《存在与虚无》，创作《苍蝇》 |
| 1945 | 创办《现代》杂志，演讲"存在主义是一种人道主义" |
| 1945-1949 | 出版《自由之路》三部曲 |
| 1952-1956 | 与法共（PCF）紧密合作 |
| 1957 | 开始撰写《辩证理性批判》 |
| 1960 | 出版《辩证理性批判》第一卷 |
| 1964 | 获诺贝尔文学奖，拒绝接受 |
| 1971-1972 | 出版《家庭的白痴》 |
| 1980.4.15 | 去世，5万人送葬 |

## 思想影响
- 胡塞尔（现象学方法）
- 海德格尔（存在哲学）
- 黑格尔（辩证法、主奴关系）
- 马克思（历史唯物主义）
- 笛卡尔（我思）
