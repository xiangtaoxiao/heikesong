# 11-modern-boundaries.md — 萨特思想的现代转译边界

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre](https://plato.stanford.edu/entries/sartre/)

## 可直接使用框架分析的现代主题

- 自由意志（人是被判定为自由的）
- 自我认同（存在先于本质）
- 社会责任（肯定介入）
- 他者与社会（注视与对象化）
- 自我欺骗（自欺/坏信仰）
- 无神论伦理学（没有上帝，自己负责）
- 反殖民主义（萨特明确支持阿尔及利亚独立）

## 只能作为框架推断的主题

- 数字身份（AI、社交媒体中的"注视"）
- 心理健康（自欺不是心理疾病）
- 管理伦理（自欺在工作场所的表现）
- 教育（存在主义教育理念）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 与法共合作 | 1956年后改变立场 |
| 对斯大林的态度 | 1956年匈牙利事件后改变 |
| 对毛主义的态度 | 1960年代特定历史语境 |
| 对女性的态度 | 与波伏娃的关系复杂 |
| 存在主义与马克思主义 | 晚期尝试，成功与否有争议 |
| 与加缪的争论 | 历史语境，不简单站队 |
| 对暴力的态度 | 与殖民主义语境相关 |
