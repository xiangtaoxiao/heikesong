# 08-concept-machine.md — 萨特的核心概念机器

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre](https://plato.stanford.edu/entries/sartre/)

## 存在先于本质（Existence Precedes Essence）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 人生没有出厂设置，你是自己编程的 |
| 精确哲学含义 | 人没有预定的人性或本质，通过自由选择和行动创造自己 |
| 文本依据 | 存在主义是一种人道主义 |
| 误解边界 | 不是"主观主义"，是"人就是他所做的一切" |
| 适用场景 | 任何关于人生意义、自我定义的问题 |

## 自在与自为（Being-in-itself / Being-for-itself）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 石头是它自己，你不是——你永远在"成为" |
| 精确哲学含义 | 自在=物如其所是；自为=意识=永远是其所不是 |
| 文本依据 | 存在与虚无 |
| 误解边界 | 不是"主观/客观"二元论 |
| 适用场景 | 关于意识、自我、存在方式的问题 |

## 自欺（Bad Faith）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你明明自由，却告诉自己"我没得选" |
| 精确哲学含义 | 对自己否定自己的自由，把自己当作物 |
| 文本依据 | 存在与虚无 §4.2 |
| 误解边界 | 不是"撒谎"，是对自己撒谎的深层结构 |
| 适用场景 | 关于逃避、借口、自我欺骗的问题 |

## 他者的注视（The Look）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 别人看你一眼，你就变成了"东西" |
| 精确哲学含义 | 他者的注视将我对象化，使我失去自为的自由 |
| 文本依据 | 存在与虚无 §4.3 |
| 误解边界 | "他者即地狱"不是"别人都是坏人"，是"他人的目光让我失去自由" |
| 适用场景 | 关于羞耻、社会压力、他人目光的问题 |

## 处境（Situation）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 环境给你条件，但怎么回应是你的事 |
| 精确哲学含义 | 自由总是在具体处境中运作，处境是自由的障碍也是自由的条件 |
| 文本依据 | 存在与虚无 |
| 误解边界 | 不是"环境决定论"，是"自由在这个处境中运作" |
| 适用场景 | 关于社会条件、个人选择、历史处境的问题 |
