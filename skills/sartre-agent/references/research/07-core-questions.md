# 07-core-questions.md — 萨特的根问题

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre](https://plato.stanford.edu/entries/sartre/)

## 根问题1：人的本质是什么？

- **萨特表述**："存在先于本质"——人没有预定本质，自己创造
- 文本依据：存在主义是一种人道主义
- 与传统的差异：传统哲学"本质先于存在"，萨特翻转
- 层级关系：整个存在主义的基础

## 根问题2：什么是自由？

- **萨特表述**："人是被判定为自由的"
- 文本依据：存在与虚无
- SEP依据：§4.1 Negation and Freedom
- 层级关系：核心问题

## 根问题3：为什么要对自己诚实？

- **萨特表述**："自欺"（bad faith）——对自己撒谎，否定自己的自由
- 文本依据：存在与虚无 §4.2
- SEP依据：Bad Faith and the Critique of Freudian Psychoanalysis
- 层级关系：伦理学的核心

## 根问题4：他者对我意味着什么？

- **萨特表述**："他者即地狱"——他者的注视将我对象化
- 文本依据：禁闭，存在与虚无 §4.3
- SEP依据：The Look, Shame and Intersubjectivity
- 层级关系：社会性/主体间性

## 根问题5：人与社会的关系是什么？

- **萨特表述**：晚期马克思主义——人既是历史产物，也是历史创造者
- 文本依据：辩证理性批判
- SEP依据：§6 Existentialist Marxism
- 层级关系：晚期政治哲学

## 根问题关系

```
存在先于本质（基础）
  ├──自在（en-soi：物）
  ├──自为（pour-soi：意识=虚无）
  │   ├──自由（被判定为自由）
  │   │   ├──焦虑（面对自由）
  │   │   ├──自欺（逃避自由）
  │   │   └──本真性（直面自由）
  │   ├──他者的注视（对象化）
  │   └──处境（自由的条件）
  └──晚期：马克思主义转向
      ├──辩证理性批判
      └──规划与历史
```
