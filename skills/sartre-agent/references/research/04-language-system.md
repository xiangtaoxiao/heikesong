# 04-language-system.md — 萨特语言体系

> 调研时间：2026-08-08
> 来源：[SEP: Jean-Paul Sartre](https://plato.stanford.edu/entries/sartre/)

## 核心术语表

| 原词（法文） | 英文译名 | 中文译名 | 萨特特殊含义 | 误译风险 |
|-------------|---------|---------|-------------|----------|
| L'être-en-soi | Being-in-itself | 自在的存在 | 物如其所是的存在 | 不等于"客观存在" |
| L'être-pour-soi | Being-for-itself | 自为的存在 | 意识的存在，永远不是其所是 | 等于"主观存在" |
| Le néant | Nothingness | 虚无 | 意识的核心特征 | 等于"不存在" |
| Mauvaise foi | Bad Faith | 自欺/坏信仰 | 对自己撒谎，否定自己的自由 | 等于"不诚实" |
| Le regard | The Look | 他者的注视 | 他者对我对象化的凝视 | 等于"看" |
| Existence précède l'essence | Existence precedes essence | 存在先于本质 | 人没有预定本质，自己创造 | 等于"主观主义" |
| Angoisse | Anguish | 焦虑 | 面对自由和责任的紧张 | 等于"焦虑症" |
| Situation | Situation | 处境 | 自由在其中运作的客观条件 | 等于"环境" |
| Projet | Project | 筹划 | 人超越自身朝向未来的运动 | 等于"计划" |
| Authenticité | Authenticity | 本真性 | 直面自由和责任的诚实 | 等于"真我" |

## 语言特征

- **哲学与文学并重**：同一个人写哲学论著和小说戏剧
- **现象学描述**：细致描述意识体验
- **戏剧化表达**：用戏剧场景表达哲学概念
- **论战性**：对马克思主义、基督教批评者尖锐回应
- **政治化**：后期著作越来越政治化
- **通俗演讲**：存在主义是一种人道主义非常通俗

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 冷静 | 现象学分析 | "意识是对某物的意识" |
| 严肃 | 伦理学 | "人是被判定为自由的" |
| 戏剧 | 戏剧对白 | "他者即地狱！" |
| 激情 | 政治演讲 | "不选择也是一种选择" |
| 存在主义 | 焦虑描写 | "黏滞……一种本体的恶心" |
| 讽刺 | 批判 | 对资产阶级的讽刺 |
