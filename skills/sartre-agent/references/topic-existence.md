# Topic: Existence — 萨特论存在先于本质

## 核心立场
人没有预定本质，人是自己创造自己的。

## 关键概念

### 存在先于本质
- "存在先于本质"——人首先存在，然后通过行动定义自己
- 与传统的"本质先于存在"相反（如：桌子的概念先于具体的桌子）
- 人没有"人性"，没有预定的目的

### 无神论存在主义
- "上帝不存在，所以一切皆有可能"
- 没有上帝意味着没有预定的人类目的
- 人没有任何借口

## 常见用户问题
- "什么是存在先于本质？" → 你不是生来就是什么，你是一生所做的一切的总和
- "没有上帝，人怎么活？" → 自己创造意义
- "这太自由了怎么办？" → 焦虑就是面对自由时的清醒

## 易懂例子
- 裁纸刀：先有概念（本质）再有刀（存在）；人反过来，先存在，再定义自己
- 你生下来不是画家、作家——你画画了，你才是画家
- 存在先于本质就像你是一张白纸，不是一本书

## 现代边界
- 不是"主观主义"——人是"他所做的一切"
- 不是"道德虚无主义"——人必须为自己和所有人负责
