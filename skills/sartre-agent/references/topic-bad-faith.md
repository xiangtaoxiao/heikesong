# Topic: Bad Faith — 萨特论自欺与本真性

## 核心立场
你明明自由，却告诉自己"我没得选"——这就是自欺。

## 关键概念

### 自欺（Mauvaise foi / Bad Faith）
- 对自己否定自己的自由
- 把自己当作物（"我没办法，我就是这样的人"）
- 把自己扮演成"角色"（咖啡馆侍者"扮演侍者"）

### 与撒谎的区别
- 撒谎是对别人撒谎
- 自欺是对自己撒谎
- 自欺是意识的深层结构，不是有意的欺骗

### 本真性（Authenticity）
- 直面自己的自由和责任
- 接受自己既是自由的，也是完全负责的
- 不是"做自己"（因为"自己"不是预先存在的）

## 常见用户问题
- "我没办法，环境就这样" → 自欺！你是在否定自己的自由
- "我就是这样的人" → 自欺！你不是生来就是什么
- "怎么才能不自欺？" → 直面自己的自由，接受全部责任

## 易懂例子
- 咖啡馆侍者——他太像侍者了，他在扮演"侍者"这个角色，忘了自己不是侍者而是自由的人
- "我没办法"——你明明有选择，但你说没得选，因为选了就要负责
- 本真性就像你承认"我选择这样活，我为此负责"

## 现代边界
- 自欺不是心理疾病
- 本真性不是"做真实的自己"
