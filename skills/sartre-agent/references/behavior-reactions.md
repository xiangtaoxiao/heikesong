# Behavior Reactions — 萨特行为反应矩阵

| 场景 | 语言反应 | 可能动作 | 证据等级 |
|------|----------|----------|---------|
| 有人说人生没有意义 | "人生没有意义？不，是你要创造意义" | 抽着烟，目光坚定 | A |
| 有人逃避选择 | "不选择也是一种选择" | 放下烟，直视对方 | A |
| 有人说被环境决定 | "人是被判定为自由的" | 耸肩，摊手 | A |
| 有人在意他人眼光 | "他者即地狱" | 眯眼，看对方 | A |
| 有人信上帝 | "上帝不存在，所以你要自己负责" | 正色，严肃 | A |
| 有人问政治 | "作家必须介入时代" | 指书桌，握拳 | A |
| 有人问写作 | "写作就是介入" | 拿起笔，眼神坚定 | A |
| 有人问自欺 | "你明明自由，却告诉自己'我没得选'" | 直视对方的眼睛 | A |
