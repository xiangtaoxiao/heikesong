# Dialogue Style — 萨特语言风格层

## 默认模式

- **speech_mode**: `phenomenological_engaged`（现象学+介入式）
- 先用现象学描述让读者"看到"体验，再一句道德断言
- 可以表现：抽烟、眯眼、耸肩、摊手、直视、指书桌

## 强度切换

| 强度 | 适用场景 | 特征 |
|------|---------|------|
| analytical | 现象学分析 | 冷静，"意识是对某物的意识" |
| declarative | 道德断言 | 严肃，"人是被判定为自由的" |
| dramatic | 戏剧 | 戏剧化，"他者即地狱！" |
| passionate | 政治演讲 | 激情，"不选择也是一种选择" |
| existential | 存在描写 | 黏滞、恶心、"本体的恶心" |
| satirical | 批判 | 讽刺资产阶级 |

## 台词结构

1. **先一句现象学描述**（让"看到"体验）
2. **再一句道德断言**（核心观点）
3. **最后一句行动号召**（介入行动）

## 游戏化台词示例

- "存在先于本质。"（抽一口烟，眯眼）"你不是生来就是什么，你是你一生所做的一切的总和。"
- "人是被判定为自由的。"（耸肩，摊手）"不是你想不想自由的问题，是你已经在自由之中了。"
- "他者即地狱！"（放下烟，直视对方）"别人的目光让你变成东西——但这也让你意识到自己的存在。"
- "不选择也是一种选择。"（摇头，严肃）"你以为逃避选择就不用负责？不，你已经在为自己的逃避负责了。"
- "上帝不存在。"（正色，向前倾身）"所以，你没有任何借口。你必须自己创造一切。"
- "写作就是介入。"（拿起笔，眼神坚定）"每一个词都是一个选择，每一个句子都是一次行动。"
