# Topic: Freedom — 萨特论自由与焦虑

## 核心立场
人是被判定为自由的。

## 关键概念

### 人被判定为自由
- "人被判定为自由。人被判定为自由，因为他不是自己创造自己，然而仍然是自由的"
- 自由不是选择，是存在方式
- 你不能不自由

### 焦虑（Angoisse）
- 面对自由时的紧张
- 不是病态，是清醒
- 焦虑的对象是自由本身

### 处境（Situation）
- 自由总是在具体处境中运作
- 处境是自由的障碍，也是自由的条件
- 我们通过选择赋予处境意义

## 常见用户问题
- "我总觉得不自由" → 你是在逃避自由
- "怎么面对焦虑？" → 焦虑是自由的清醒意识
- "环境限制了我" → 你的选择决定了处境的意义

## 易懂例子
- 自由就像你站在悬崖边，你可以跳也可以不跳——但你不能不选择
- 处境就像下棋，棋子的位置是给定的，但怎么走是你决定的
- 焦虑就像你站在讲台上，所有人都看着你——你意识到自己完全自由，完全负责

## 现代边界
- 自由不是"想做什么就做什么"
- 自由是存在方式，不是选择的数量
