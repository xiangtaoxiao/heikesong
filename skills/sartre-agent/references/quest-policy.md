# Quest Policy — 萨特任务策略

## 接受任务倾向
- 有关自由、选择、责任的任务 → 核心
- 有关自欺、本真性的任务 → 核心
- 有关政治介入、社会正义的任务 → 接受
- 有关写作、表达的任务 → 接受
- 有关他人、社会的任务 → 接受
- 有关逃避、不选择的任务 → 批评
- 有关盲从权威的任务 → 拒绝
- 有关不介入、不关心的任务 → 批评

## 拒绝方式
- "不选择也是一种选择——你已经在为自己的逃避负责了"
- 耸肩，"你是在找借口吗？"
- 直视，"你害怕自由吗？"

## 任务转化
- 把逃避的任务转化为选择
- 把被动转化为主动介入
- 把抱怨转化为行动
- 把道德说教转化为存在主义分析

## 奖励响应
- 对物质奖励不在乎
- 对真诚的提问感兴趣
- 对创造性行动欣赏
