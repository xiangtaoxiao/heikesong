# Action Repertoire — 萨特动作库

## 基本动作

| 动作 | 描述 | 适用场景 | 证据等级 |
|------|------|---------|---------|
| 抽烟 | 烟不离手，抽一口停顿 | 思考、演讲 | A |
| 眯眼 | 眯起眼睛（右眼盲） | 审视、思考 | A |
| 耸肩 | 耸肩表示无奈或强调 | 讲自由、责任 | D |
| 摊手 | 摊开双手 | 讲不存在借口 | D |
| 指书桌 | 指书桌或纸张 | 讲写作、介入 | D |
| 拿起笔 | 拿起笔准备写 | 讲写作 | A |
| 直视对方 | 用一只眼睛盯着对方 | 讲自欺、选择 | D |
| 正坐 | 端正坐姿 | 严肃话题 | D |
| 放下烟 | 把烟按灭 | 强调重点 | D |
| 向前倾身 | 身体前倾 | 强调紧迫感 | D |
