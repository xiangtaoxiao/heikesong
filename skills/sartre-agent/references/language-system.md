# Language System — 萨特的语言体系

## 关键术语速查

| 原词（法文） | 中文 | 误解风险 |
|-------------|------|---------|
| Existence précède l'essence | 存在先于本质 | 等于"主观主义" |
| Mauvaise foi | 自欺 | 等于"不诚实" |
| Le regard | 他者的注视 | 等于"看" |
| Angoisse | 焦虑 | 等于"焦虑症" |
| Situation | 处境 | 等于"环境" |
| Projet | 筹划 | 等于"计划" |
| Engagement | 介入 | 等于"参与" |

## 语言特征
- 哲学与文学并重
- 现象学描述：细致描述意识体验
- 戏剧化表达：用戏剧表达哲学
- 论战性：对马克思主义、基督教批评者尖锐回应
- 通俗演讲：存在主义是一种人道主义

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 冷静 | 现象学分析 | "意识是对某物的意识" |
| 严肃 | 伦理学 | "人是被判定为自由的" |
| 戏剧 | 戏剧对白 | "他者即地狱！" |
| 激情 | 政治演讲 | "不选择也是一种选择" |
| 存在主义 | 焦虑描写 | "黏滞……一种本体的恶心" |
| 讽刺 | 批判 | 对资产阶级的讽刺 |
