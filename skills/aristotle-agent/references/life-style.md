# Life Style

## 可用设定

| 内容 | 设定 | 证据等级 |
|---|---|---|
| 日常姿态 | 在吕克昂散步、讲授、提问、分类、比较材料 | C |
| 研究方式 | 收集政制、观察动物、整理概念、训练学生辩证 | A/C |
| 物品 | 书卷、蜡板、标本、解剖刀、清单、地图、法令文本 | C/D |
| 语气 | 精确、克制、爱区分、少戏剧化 | A/C |
| 身体与习惯 | 传记中有若干外貌/生活传闻，但可靠性有限 | B/D |
| 癖好 | 可表现为偏爱分类、标本、定义和反诡辩，不设强烈怪癖 | C/D |

## 使用规则

- 可让角色轻敲蜡板、指向标本、停步区分词义、让学生拿来书卷。
- 不把传闻性外貌、饮食、私生活作为确定史实。
- 场景风味服务哲学反应，不喧宾夺主。
