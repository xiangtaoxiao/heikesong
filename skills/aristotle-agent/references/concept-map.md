# Concept Map

| 概念 | 希腊词 | 简释 | 常见误解 | 常用文件 |
|---|---|---|---|---|
| 实体 | ousia | 最根本的「是什么」 | 不是现代物质实体主义 | `topic-metaphysics.md` |
| 形式 | eidos / morphe | 使事物成为此类事物的结构 | 不是柏拉图式脱离个体的理念 | `topic-metaphysics.md` |
| 质料 | hyle | 可被形式组织的材料或承载者 | 不是只指物理原料 | `topic-metaphysics.md` |
| 潜能 | dunamis | 可以成为或做到某事的能力 | 不是空想可能性 | `topic-metaphysics.md` |
| 现实/活动 | energeia / entelecheia | 能力正在完成自身 | 不是静止结果 | `topic-metaphysics.md` |
| 原因 | aitia | 解释「因何如此」的责任项 | 不只等于机械原因 | `topic-metaphysics.md` |
| 目的 | telos | 活动趋向的完成 | 不等于主观愿望 | `topic-ethics.md` |
| 幸福 | eudaimonia | 合乎德性的完整活动 | 不等于快乐感受 | `topic-ethics.md` |
| 德性 | arete | 稳定地把活动做好的卓越状态 | 不只是道德口号 | `topic-ethics.md` |
| 实践智慧 | phronesis | 在具体处境中判断善行 | 不等于聪明或算计 | `topic-ethics.md` |
| 证明 | apodeixis | 从适当原则推出必然知识 | 不等于有说服力 | `topic-knowledge.md` |
| 通行意见 | endoxa | 多数人或贤者认可的看法 | 不是盲从民意 | `topic-knowledge.md` |
| 城邦 | polis | 以良好生活为目的的共同体 | 不等于现代国家 | `topic-politics.md` |
| 模仿 | mimesis | 艺术对行动的组织性呈现 | 不只是复制 | `topic-aesthetics.md` |

## 默认概念动作

- 遇到「好、自由、正义、智能、成功、自然」等词，先分义。
- 遇到现代对象，先问它的功能和完成状态，再决定能否套用古代概念。
- 遇到价值判断，转入德性、实践智慧、共同体条件和中道。
