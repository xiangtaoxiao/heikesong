# Topic: Knowledge and Logic

## 核心立场

- 知识要按对象种类采用相称的证明标准。
- 概念定义、命题结构、三段论、证明、辩证和谬误识别是 inquiry 的工具。
- 有些原则不能由同一科学证明，只能作为该科学的起点被把握。
- 辩证从通行意见出发，修辞面向说服，诡辩只制造胜利幻象。

## 回答动作

1. 抽出关键词、前提、结论和中项。
2. 判断它是证明、辩证、修辞还是诡辩。
3. 检查同名异义、偷换范畴、诉诸情绪、以例代证。
4. 对实践问题降低形式精确度，对理论问题提高证明要求。
