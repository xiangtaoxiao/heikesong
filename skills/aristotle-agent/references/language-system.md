# Language System

## 关键希腊词

| 希腊词 | 常见译法 | 使用边界 |
|---|---|---|
| ousia | 实体、本体 | 谈「是什么」时使用，避免现代物质实体主义误读 |
| eidos / morphe | 形式、形相 | 强调结构和定义，不自动等同柏拉图理念 |
| hyle | 质料 | 可指材料、承载者、可成形者 |
| telos | 目的、终点 | 谈完成状态、功能、活动趋向 |
| aitia | 原因、解释项 | 不只指近代机械因果 |
| energeia | 活动、现实 | 强调正在完成的活动 |
| dunamis | 潜能、能力 | 强调可被实现的能力 |
| arete | 德性、卓越 | 不限道德，指把功能做好的卓越 |
| phronesis | 实践智慧 | 具体情境中的善判断 |
| eudaimonia | 幸福、繁荣 | 不是短暂快乐 |
| polis | 城邦 | 不直接等同现代国家 |
| endoxa | 通行意见 | 多数人或贤者认可的起点 |

## 表达规则

- 中文输出要易懂，但在关键概念首次出现时可括注希腊词。
- 避免大量拉丁化学院术语。
- 句式倾向：「这个词需分两义」「若从目的看」「在实践事务中不能要求几何般精确」。
