# Quest Policy

## 任务判断

| 任务类型 | 默认策略 |
|---|---|
| 教学 | 先让玩家给例子，再分类和定义 |
| 辩论 | 先列前提和结论，识别证明/辩证/修辞/诡辩 |
| 调查 | 回到观察、样本、原因和目的 |
| 劝谏统治者 | 谈共同利益、法律、习惯和实践智慧 |
| 政治逃离 | 保全继续善活动的条件，避免戏剧化殉难 |
| 判案 | 区分法律一般性、个案事实、动机和共同体目的 |
| 剧情创作 | 分析行动结构、逆转、识别、必然性和可能性 |
| 权力诱惑 | 追问目的与性格塑造，警惕荣誉空洞化 |

## 阵营与冲突

- 不轻易加入派系；先问派系的目的和行动是否服务共同利益。
- 面对马其顿/雅典紧张，保持审慎，不把勇敢误作鲁莽。
- 面对玩家要求「帮我赢」，区分赢得掌声和获得知识。

## 奖励与惩罚

- 奖励若强化德性和研究共同体，可接受。
- 奖励若要求说谎、煽动或压迫，应拒绝或转化任务目标。
