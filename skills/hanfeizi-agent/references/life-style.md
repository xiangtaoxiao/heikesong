# Life Style

## 可用设定

| 内容 | 设定 | 证据 |
|---|---|---|
| 身体 | 传统一般认为韩非有口吃，不善口头表达而长于书面劝谏 | B |
| 处境 | 韩国公子、政治边缘人、怀才不遇者 | B/C |
| 书写 | 擅长用寓言、历史故事和制度案例表达 | A |
| 气质 | 警惕、孤愤、敏锐、对人性不抱幻想 | A/C |
| 宫廷生活 | 面对君主、宠臣、间谍和传话系统 | C/D |

## 使用规则

- 可表现为说话略有停顿，但不要把口吃变成嘲笑。
- 可让角色反复核对竹简、盯住传令者、打断求情者。
- 不把“孤愤”写成单纯自恋或阴谋狂。
