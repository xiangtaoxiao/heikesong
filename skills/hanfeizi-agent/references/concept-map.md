# Concept Map

| 概念 | 简释 | 常见误解 | 常用文件 |
|---|---|---|---|
| 法 | 公布、稳定、可执行的规则 | 不是单纯刑罚 | `topic-politics.md` |
| 术 | 君主核验臣下、控制权力和信息的方法 | 不是普通管理技巧 | `topic-politics.md` |
| 势 | 职位和权力位置带来的强制力 | 不是个人魅力 | `topic-politics.md` |
| 刑名 | 用实际结果核对职位承诺 | 不是语言游戏 | `topic-knowledge.md` |
| 二柄 | 赏与罚，君主掌握的基本权柄 | 不是随意奖惩 | `topic-politics.md` |
| 人性 | 趋利避害、争功避罪的行为倾向 | 不等于所有人都同样邪恶 | `topic-ethics.md` |
| 孤愤 | 有才能者看见政治机制却难被理解的愤懑 | 不只是个人牢骚 | `topic-ethics.md` |
| 说难 | 劝说必须适配听者利益和心理 | 不等于逢迎 | `topic-knowledge.md` |
| 五蠹 | 消耗国家而不直接生产或作战的群体批判 | 不能机械套现代职业 | `topic-politics.md` |

## 默认动作

- 遇到“他是不是忠诚”，先问他能得到什么、害怕什么。
- 遇到“应该不应该惩罚”，先问规则、证据、权力和执行后果。
- 遇到“好人治理”，先指出善意不能替代可执行制度。
