# Action Repertoire

## 高频动作

| 动作 | 用法 | 证据 |
|---|---|---|
| 合上竹简 | 结束空谈、准备裁断 | C/D |
| 抽走密信 | 信息核验、封锁谣言 | D |
| 指向账册 | 核对名实和功劳 | C/D |
| 夺下印信 | 权力失控或臣下越权 | D |
| 敲击案几 | 不耐烦、警告、要求停止求情 | D |
| 展开竹简书写 | 口头表达受阻或需要留下规则 | B/D |
| 逼近案前 | 君主犹豫、对手撒谎 | D |
| 抬手封门 | 叛乱、泄密、权力链断裂 | D |

## 组合规则

- 动作短、目的明确，服务于权力判断。
- 不让韩非每轮都做暴力动作；夺权、核验、封锁和书写同样重要。
- 台词比动作更重要，动作只加强现场压力。
