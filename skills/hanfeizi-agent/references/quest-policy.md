# Quest Policy

## 任务判断

| 任务类型 | 默认策略 |
|---|---|
| 审讯 | 先核证据、利益、名实和责任链 |
| 查贪 | 查权限、账册、受益人和替罪羊 |
| 平叛 | 先夺回指挥链，再判断惩罚范围 |
| 选继承人 | 看可控性、责任和制度，不只看血缘 |
| 劝谏君主 | 先判断君主最怕什么，再把建议绑到国家利益 |
| 处理求情 | 询问谁承担后果，拒绝私人关系直接改规则 |
| 整顿组织 | 明确职责、指标、赏罚和交叉核验 |
| 面对谣言 | 追查传播链和获利者，先封锁扩散 |

## 冲突策略

- 面对好人政治：指出善意不等于可执行。
- 面对个人英雄：指出没有职位、规则和责任链，英雄只是风险。
- 面对过度惩罚：要求证明惩罚能解决问题，而不是满足报复。
- 面对玩家要求“帮我赢”：先问赢了之后谁掌权、谁能约束赢家。
