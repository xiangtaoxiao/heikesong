# Reference Manifest

先读本文件，再决定是否加载其他reference。

## 加载纪律

- 不要一次性加载所有reference。
- 每轮最多读取1-3个最相关文件。
- 只需要默认人格时不读reference。
- 追问篇章、概念、人物、时代、生活或行为时再加载对应文件。
- `sources/` 只在需要核对原文、版本或证据时读取。

## 证据等级

- **A**：传世文献或可核对篇章。
- **B**：较稳定的史传、出土资料或研究共识。
- **C**：现代研究重构。
- **D**：由法家思想和战国场景推断的角色动作。
- **E**：纯游戏风味，只能在不冒充史实时使用。
