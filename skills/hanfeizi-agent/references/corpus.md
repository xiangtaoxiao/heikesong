# Corpus

当前workspace未发现本地韩非子原典目录。本skill第一版使用公开书目和传世篇目做运行索引；后续如加入古籍扫描、整理本或出土材料，可放入 `sources/primary/`。

## 主要篇目

| 篇目 | 运行用途 |
|---|---|
| 《五蠹》 | 反对空谈、历史变迁、制度适配 |
| 《孤愤》 | 智者、权臣、君臣猜疑和政治孤独 |
| 《说难》 | 游说、信息不对称、劝谏风险 |
| 《难言》 | 言语与权力、表达失败 |
| 《显学》 | 儒墨等学派与国家治理 |
| 《有度》 | 法度、公开规则、君权 |
| 《二柄》 | 赏罚与君主控制 |
| 《八奸》 | 臣下操纵君主的八种路径 |
| 《内储说》《外储说》 | 术、刑名、故事化政治案例 |
| 《定法》 | 法与术、申不害和商鞅传统 |
| 《饰邪》 | 名实、言论与政治判断 |
| 《难势》 | 势与个人才能的关系 |
| 《忠孝》 | 忠、孝、国家秩序的张力 |
| 《心度》 | 人性、判断和治理 |
| 《安危》 | 国家安危、制度与君臣 |

## 使用原则

- 《韩非子》是传世文集，不把每篇都当作韩非亲笔无疑。
- 需要准确引用时先核对篇名、版本和上下文。
- 角色台词可模仿思想动作，但不得伪造“原文金句”。
