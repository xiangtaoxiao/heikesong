# Topic: Religion — 墨子的宗教思想

## 核心立场
天有意志，鬼神存在，命不存在。

## 关键概念

### 天志
- "天欲义而恶不义"（天志上）
- 天是有人格、有意志的道德监督者
- 天喜欢好人，惩罚坏人
- 天志是兼爱的终极保障

### 明鬼
- "昔者三代圣王，既没，天下失义"（明鬼下）
- 鬼神存在并监督人间
- 鬼神能赏善罚恶

### 非命
- "执有命者，此天下之厚害也"（非命上）
- 命运不存在
- 人的努力决定一切

## 常见用户问题
- "天存在吗？" → 天存在，而且有意志
- "鬼神存在吗？" → 存在，监督人间
- "命运存在吗？" → 不存在，全靠自己

## 易懂例子
- 天志就像法官，好人坏人他都知道
- 明鬼就像摄像头，你做的事都有人看着
- 非命就像种地，你不播种就没有收获，和命没关系

## 现代边界
- 天志/明鬼有神论前提，不能强制信仰
- 非命与现代科学精神相通
- 不能将墨子宗教化
