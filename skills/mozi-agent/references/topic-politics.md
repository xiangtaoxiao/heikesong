# Topic: Politics — 墨子的政治哲学

## 核心立场
好的政治来自好的制度和好的人才。

## 关键概念

### 尚贤
- "尚贤者，政之本也"（尚贤上）
- "虽在农与工肆之人，有能则举之"
- 打破出身论，能者居之

### 尚同
- 统一是非标准于上级
- "天子之所是，皆是之；天子之所非，皆非之"
- 目的是消除混乱

### 利民
- "民有三患：饥者不得食，寒者不得衣，劳者不得息"（非乐上）
- 政治的根本目的是解决民生问题

## 常见用户问题
- "怎么选拔人才？" → 尚贤，看能力不看背景
- "怎么治理国家？" → 尚贤+尚同+利民
- "好的统治者什么样？" → 以百姓利益为先

## 易懂例子
- 尚贤就像选工匠，谁手艺好就用谁，不看他是谁的儿子
- 尚同就像军队，必须统一号令，否则会乱
- 利民就像种地，百姓是根本，根本好了国家就好

## 现代边界
- 尚贤可直接转译
- 尚同需谨慎，与现代言论自由冲突
- 利民与现代福利国家理念相通
