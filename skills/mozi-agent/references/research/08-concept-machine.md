# 08-concept-machine.md — 墨子的核心概念机器

> 调研时间：2026-08-08

## 兼爱（Inclusive Care / Universal Love）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 爱别人就像爱自己一样，不分亲疏远近 |
| 精确哲学含义 | 无差别地爱所有人，消除自私的分别心 |
| 文本依据 | "兼相爱则治，交相恶则乱"（兼爱上） |
| 误解边界 | 不是不爱家人，是先爱家人再推及他人 |
| 适用场景 | 任何关于人际关系、社会和谐的问题 |

## 非攻（Opposing Aggressive War）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 反对侵略战争，但不反对自卫 |
| 精确哲学含义 | 谴责"攻"（侵略），不反对"诛"（讨伐暴君） |
| 文本依据 | "非攻"三篇，以"窃桃李"类比"攻国" |
| 误解边界 | 不是绝对和平主义，正义战争可以支持 |

## 尚贤（Promoting the Worthy）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 有本事的人就应该当官，不看背景 |
| 精确哲学含义 | 以能力而非出身选拔官员 |
| 文本依据 | "尚贤者，政之本也"（尚贤上） |
| 误解边界 | 不是简单的精英政治，是打破世袭 |

## 天志（Will of Heaven）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 天有意志，喜欢好人惩罚坏人 |
| 精确哲学含义 | 天是有人格、有意志的道德监督者 |
| 文本依据 | "天欲义而恶不义"（天志上） |
| 误解边界 | 不是基督教的神，是人格化的道德秩序 |

## 非命（Opposing Fatalism）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 没什么命运，全靠自己努力 |
| 精确哲学含义 | 否定宿命论，强调人的能动性 |
| 文本依据 | "执有命者，此天下之厚害也"（非命上） |
| 误解边界 | 不是不承认客观规律 |

## 三表法（Three Models）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 判断对错要看三个标准 |
| 精确哲学含义 | 本之古者圣王之事、原察百姓耳目之实、发以为刑政观其利 |
| 文本依据 | "何谓三表？有本之者，有原之者，有用之者"（非命上） |
| 误解边界 | 不是完全的经验主义 |
