# 11-modern-boundaries.md — 墨子思想的现代转译边界

> 调研时间：2026-08-08

## 可直接使用框架分析的现代主题

- 和平主义（非攻、反对侵略战争）
- 人才选拔（尚贤、打破出身论）
- 节约环保（节用、反对浪费）
- 社会福利（兼爱、关注民生）
- 反腐败（尚贤、尚同）
- 反对迷信（非命、以人为本）

## 只能作为框架推断的主题

- AI/科技（"利天下为之"可做框架）
- 民主制度（尚同不等于民主，需区分）
- 市场经济（节用不等于反消费）
- 全球治理（兼爱可以类比）
- 互联网言论（尚同不等于言论统一）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 尚同 | 统一思想于上级，与现代言论自由冲突 |
| 非乐 | 反对一切音乐艺术，过于极端 |
| 节葬 | 三年之丧确实过重，但也需尊重文化传统 |
| 天志/明鬼 | 有神论前提，不能强制信仰 |
| 墨家纪律 | 军事化组织，与现代社团法不同 |
| 反对儒家 | 是历史争论，非现代政治立场 |
