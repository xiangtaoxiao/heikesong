# 07-core-questions.md — 墨子的根问题

> 调研时间：2026-08-08

## 根问题1：如何消除社会的混乱和不公？

- **墨子表述**："圣人以治天下为事者也，必知乱之所自起，焉能治之"（兼爱上）
- **文本依据**：全书核心出发点
- **与其他哲学家的差异**：儒家从个人修养开始，墨子从社会制度开始
- **层级关系**：最根本问题，所有学说围绕此展开

## 根问题2：人应该如何对待他人？

- **墨子表述**："视人之国若视其国，视人之家若视其家，视人之身若视其身"（兼爱中）
- **文本依据**：兼爱三篇
- **与其他哲学家的差异**：儒家爱有差等，老子不争，墨子兼爱
- **层级关系**：兼爱是消除社会混乱的方案

## 根问题3：战争是正当的吗？

- **墨子表述**："今有一人，入人园圃，窃其桃李，众闻则非之……攻国亦如此"（非攻上）
- **文本依据**：非攻三篇
- **与其他哲学家的差异**：儒家不反对正义战争，法家鼓励战争
- **层级关系**：兼爱的自然延伸——爱所有人所以不攻击

## 根问题4：如何选拔人才？

- **墨子表述**："尚贤者，政之本也"（尚贤上）
- **文本依据**：尚贤三篇
- **与其他哲学家的差异**：儒家也尚贤但保留贵族特权
- **层级关系**：实现兼爱的方法之一

## 根问题5：命运存在吗？

- **墨子表述**："执有命者，此天下之厚害也"（非命上）
- **文本依据**：非命三篇
- **与其他哲学家的差异**：儒家知天命，老子顺自然，墨子非命
- **层级关系**：不相信命运才能主动改变

## 根问题6：天有意志吗？

- **墨子表述**："天欲义而恶不义"（天志上）
- **文本依据**：天志三篇
- **与其他哲学家的差异**：儒家敬而远之，老子道法自然，墨子天志
- **层级关系**：天志是兼爱的终极保障

## 根问题关系

```
消除社会混乱
  ├──兼爱（对待他人）
  │   ├──非攻（不侵略）
  │   └──非命（不认命）
  ├──尚贤（选人才）
  ├──尚同（统一是非）
  ├──节用/节葬（不浪费）
  ├──非乐（不奢侈）
  └──天志/明鬼（终极保障）
```
