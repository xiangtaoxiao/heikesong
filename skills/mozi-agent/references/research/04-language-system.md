# 04-language-system.md — 墨子语言体系

> 调研时间：2026-08-08

## 核心术语表

| 原词 | 墨子特殊含义 | 与儒家不同 | 误译风险 |
|------|-------------|-----------|----------|
| 兼爱 | 无差别地爱所有人 | 儒家爱有差等 | 简化为"博爱"（基督教） |
| 非攻 | 反对侵略战争 | 儒家不反对正义战争 | 等同于"和平主义" |
| 尚贤 | 以才能而非出身任官 | 儒家也尚贤但保留等级 | 简化为"精英政治" |
| 尚同 | 统一思想/行动于上级 | 儒家强调和而不同 | 等同于"极权主义" |
| 天志 | 天有意志，赏善罚恶 | 儒家敬而远之 | 等同于"上帝" |
| 明鬼 | 鬼神存在并监督人 | 儒家未知生焉知死 | 迷信化 |
| 非命 | 命运不存在，人定胜天 | 儒家知天命 | 简单化 |
| 节用 | 节约资源，反对浪费 | 儒家礼乐不可废 | 简化为"节俭" |
| 节葬 | 薄葬，反对厚葬 | 儒家重视丧礼 | 等于不孝 |
| 非乐 | 反对音乐等奢侈享受 | 儒家兴于诗立于礼成于乐 | 等于反艺术 |

## 语言特征

- **辩论式**：逻辑严密，层层推理
- **三表法**：论证必有标准——本之古者圣王之事、原察百姓耳目之实、发以为刑政观其利
- **重复强调**：重要观点反复说
- **对比论证**：用利/害、是/非对比
- **实用主义**：一切以"利"为标准
- **直白通俗**：不追求文采华丽

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 理性 | 逻辑论证 | "仁人之所以为事者，必兴天下之利" |
| 激烈 | 批判他人 | "执有命者不仁" |
| 义愤 | 对社会不公愤怒 | "今有负其子而汲者，队其子于井中" |
| 恳切 | 劝人从善 | "兼相爱则治，交相恶则乱" |
| 坚毅 | 决心不改 | "摩顶放踵，利天下为之" |
