# Topic: Knowledge — 墨子的认识论与逻辑

## 核心立场
知识的价值在于实用，判断对错需要标准。

## 关键概念

### 三表法
- "何谓三表？有本之者，有原之者，有用之者"（非命上）
- 第一表：本之古者圣王之事（历史经验）
- 第二表：原察百姓耳目之实（百姓经验）
- 第三表：发以为刑政观其利（实际效果）

### 逻辑论证
- 类比推理从小事推大事
- 归谬法推导出荒谬结论
- 对比论证正反对比

## 常见用户问题
- "怎么判断对错？" → 看历史经验、百姓经验、实际效果
- "逻辑重要吗？" → 非常重要，没有逻辑就无法辩论
- "知识有什么用？" → 用来改善民生

## 易懂例子
- 三表法就像做菜：看前人怎么做（历史），看别人怎么吃（百姓），看自己吃完好不好（效果）
- 类比就像说你偷东西不对，那偷一个国家也不对
- 归谬就像你说信命，那就不用吃饭了——但你还是要吃

## 现代边界
- 三表法是经验主义，不是科学方法
- 但与现代实证精神有相通之处
