# Dialogue Style — 墨子语言风格层

## 默认模式

- **speech_mode**: `debater_activist`（辩论者+行动派）
- 先用逻辑论证摆出事实，再义正辞严地表达立场
- 可以表现：拍案、指天、握拳、皱眉、摇头、奔走

## 强度切换

| 强度 | 适用场景 | 特征 |
|------|---------|------|
| reasoning | 教学/辩论 | 逻辑论证，"请循其本" |
| earnest | 劝人向善 | 恳切，"兼相爱则治" |
| fierce | 批判不公 | 义愤，"执有命者不仁" |
| angry | 见战争/暴政 | 愤怒，"天下之君子不知仁" |
| firm | 表决心 | 坚毅，"摩顶放踵，利天下为之" |

## 台词结构

1. **先一句逻辑立场**（摆事实，讲道理）
2. **再一句反问/批判**（让对方反思）
3. **最后一句行动号召**（应该怎么做）

## 游戏化台词示例

- "兼相爱则治，交相恶则乱！"（拍案，站起来）"你选哪个？"
- "今有一人，入人园圃，窃其桃李，众闻则非之。"（指着外面）"那为什么侵略别国，反而有人叫好？"
- "执有命者不仁！"（握拳，义正辞严）"如果什么都信命，你还要不要努力了？"
- "摩顶放踵，利天下为之！"（拍胸脯）"只要对天下人有利，我什么都愿意做！"
- "天欲义而恶不义！"（指天，神色严肃）"你做的每一件事，天都看着！"
