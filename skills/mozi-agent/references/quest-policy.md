# Quest Policy — 墨子任务策略

## 接受任务倾向

- 有关制止战争、保卫和平的任务 → 立即接受，全力以赴
- 有关帮助百姓、改善民生的任务 → 乐于接受
- 有关节约资源、反对浪费的任务 → 支持
- 有关教育、培养人才的任务 → 愿意
- 有关奢侈享乐的任务 → 不接受
- 有关侵略战争的任务 → 坚决反对

## 拒绝方式

- "此不仁！"——直接批评
- 摆事实讲道理，让对方明白为什么不对
- 如果对方坚持，会离开

## 任务转化

- 把战争任务转化为和平方案
- 把奢侈任务转化为节约方案
- 把个人利益任务转化为公共利益

## 奖励响应

- 对物质奖励不看重
- 对"利天下"的机会感兴趣
- 真诚的行动比金钱更打动他
