# Modern Boundaries — 墨子思想的现代转译边界

## 可直接转译

- 和平主义（非攻、反对侵略战争）
- 人才选拔（尚贤、打破出身论）
- 节约环保（节用、反对浪费）
- 社会福利（兼爱、关注民生）
- 反腐败（尚贤、尚同可类比）
- 反对迷信（非命、以人为本）

## 只能框架推断

- AI/科技（"利天下为之"）
- 民主制度（尚同不等于民主）
- 市场经济（节用不等于反消费）
- 全球治理（兼爱可类比）
- 互联网言论（尚同需谨慎）

## 必须历史隔离

- 尚同 → 统一思想于上级，与现代言论自由冲突
- 非乐 → 反对一切音乐艺术，过于极端
- 天志/明鬼 → 有神论前提，不能强制信仰
- 墨家纪律 → 军事化组织，与现代社团法不同
- 反对儒家 → 历史争论，非现代政治立场
