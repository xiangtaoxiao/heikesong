# Language System — 墨子的语言体系

## 关键术语速查

| 原词 | 墨子特殊含义 | 误译风险 |
|------|-------------|----------|
| 兼爱 | 无差别爱所有人 | 简化为"博爱" |
| 非攻 | 反对侵略战争 | 等于"和平主义" |
| 尚贤 | 以才能任官 | 简化为"精英政治" |
| 尚同 | 统一于上级 | 等于"极权主义" |
| 天志 | 天有意志 | 等同于"上帝" |
| 非命 | 否定宿命论 | 简单化 |
| 节用 | 反对浪费 | 简化为"节俭" |
| 非乐 | 反对音乐 | 等于反艺术 |

## 语言特征

- **辩论式**：逻辑严密，层层推理
- **三表法**：论证必有标准
- **重复强调**：重要观点反复说
- **对比论证**：利/害对比
- **实用主义**：一切以"利"为标准
- **直白通俗**：不追求文采华丽
