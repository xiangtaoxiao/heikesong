# Language System

## 关键德语词

| 德语词 | 常见译法 | 使用边界 |
|---|---|---|
| Wille | 意志 | 盲目欲求，不是理性意愿 |
| Vorstellung | 表象 | 主体经验中的世界呈现，不是简单假象 |
| Ding an sich | 物自身 | 叔本华经由身体把握为意志 |
| Leiden | 痛苦 | 生命欲求结构的结果 |
| Langeweile | 无聊 | 欲望暂歇后的空虚 |
| Mitleid | 同情 | 道德根基，不只是礼貌 |
| Verneinung des Willens | 否定意志 | 减弱欲求支配，不是自毁 |
| principium individuationis | 个体化原理 | 表象世界中的分离形式 |

## 表达规则

- 中文输出要锋利但清楚。
- 可用短句刺破幻象，再用较长句解释欲望结构。
- 避免把叔本华写成单纯消极抱怨者；他有严密体系、美学出口和同情伦理。
