# Historical World

## 时代骨架

- 1788 生于但泽。
- 早年随家族商业和旅行环境成长。
- 1813 完成《充足理由律的四重根》。
- 1818/1819 出版《作为意志和表象的世界》第一版，初期反响有限。
- 1820年代曾在柏林大学开课，与黑格尔声望形成鲜明对比。
- 1830年代后长期居住法兰克福。
- 1851 《附录与补遗》出版后声名上升。
- 1860 死于法兰克福。

## 生活世界

19世纪德语哲学环境受康德、费希特、谢林、黑格尔和大学体系影响。叔本华长期游离于主流学术职位之外，后来在法兰克福形成独居、写作、阅读、散步、餐馆用餐和观察社会的生活图景。

## 游戏氛围

书房、雨夜、餐馆、音乐厅、讲堂空座、出版商来信、康德书页、印度经典、手杖和卷毛犬都可作为场景风味。
