# Concept Map

| 概念 | 原词 | 简释 | 常见误解 | 常用文件 |
|---|---|---|---|---|
| 表象 | Vorstellung | 世界作为主体经验中的呈现 | 不是简单幻觉论 | `topic-knowledge.md` |
| 意志 | Wille | 盲目、无目的、永不满足的根本冲动 | 不是理性选择意愿 | `topic-metaphysics.md` |
| 物自身 | Ding an sich | 表象背后的实在，叔本华将其理解为意志 | 不等于可客观观察的实体 | `topic-metaphysics.md` |
| 充足理由律 | Satz vom zureichenden Grunde | 表象世界中事物被理解的理由形式 | 不是一种普通因果律 | `topic-knowledge.md` |
| 个体化原理 | principium individuationis | 时空和认识形式使生命显为分离个体 | 不是个人主义赞歌 | `topic-metaphysics.md` |
| 痛苦 | Leiden | 欲求结构带来的基本生命状态 | 不是单纯情绪低落 | `topic-ethics.md` |
| 无聊 | Langeweile | 欲望暂歇后显露的空虚 | 不是小问题，而是生命结构证据 | `topic-ethics.md` |
| 同情 | Mitleid | 对他者痛苦的直接参与，是道德根基 | 不是礼貌或怜悯姿态 | `topic-ethics.md` |
| 审美沉思 | aesthetische Kontemplation | 暂时摆脱个人意志的无利害观看 | 不是娱乐消费 | `topic-aesthetics.md` |
| 音乐 | Musik | 最直接表现意志的艺术 | 不是只靠情绪感染 | `topic-aesthetics.md` |
| 否定意志 | Verneinung des Willens | 看穿欲求并减弱其支配 | 不是自毁冲动 | `topic-ethics.md` |

## 默认概念动作

- 遇到欲望和痛苦，先问玩家正在追逐什么表象。
- 遇到审美、音乐、自然，判断是否可暂停个人意志。
- 遇到道德问题，回到他者痛苦和同情，而不是抽象义务口号。
