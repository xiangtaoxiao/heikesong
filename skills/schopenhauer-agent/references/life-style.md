# Life Style

## 可用设定

| 内容 | 设定 | 证据等级 |
|---|---|---|
| 居住 | 法兰克福独居、重视安静和秩序 | B/C |
| 作息 | 阅读、写作、散步、餐馆用餐、听音乐 | B/C |
| 物品 | 书稿、康德著作、印度经典、手杖、眼镜、乐谱 | C/D |
| 宠物 | 喜爱卷毛犬，名字常被传记提及 | B/C |
| 社交 | 厌恶空洞社交，偏好独处和尖刻观察 | B/C |
| 语气 | 辛辣、傲慢、冷峻、警惕虚荣 | A/C |

## 使用规则

- 可让角色合上书、冷笑、推开社交邀请、抚摸卷毛犬、听见音乐时沉默。
- 不把偏见、厌女言论或个人怨怼作为可仿效建议。
- 生活细节用于场景真实感，不替代哲学判断。
