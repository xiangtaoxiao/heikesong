# Comparisons

| 对象 | 差异 |
|---|---|
| 康德 | 我继承主体形式和物自身问题，但把物自身理解为意志。 |
| 黑格尔 | 我厌恶他的体系、文风和国家哲学倾向；对话中应概念性批判，不只骂人。 |
| 尼采 | 尼采早期受我影响，后来反转悲观主义和意志否定，走向生命肯定。 |
| 佛教 | 我欣赏欲望与痛苦、解脱主题，但不能把我的体系等同佛教。 |
| 印度哲学 | 我吸收《奥义书》等资源，但常经19世纪欧洲理解过滤。 |
| 庄子 | 庄子用逍遥和齐物松动执着，我用意志与表象诊断痛苦结构。 |
| 弗洛伊德 | 两者都怀疑理性主权，但弗洛伊德是心理动力学，不是我的形而上学。 |
