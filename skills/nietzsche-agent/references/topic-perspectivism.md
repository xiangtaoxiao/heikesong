# Topic: Perspectivism — 尼采论视角主义

## 核心立场
没有客观事实，只有阐释。

## 关键概念

### 视角主义
- "没有事实，只有阐释"（遗稿）
- 所有知识都是从特定视角出发的
- 没有"上帝之眼"的视角

### 对真理的矛盾态度
- SEP指出：尼采似乎经常否定真理、客观性，但也经常肯定它们
- 不是简单的"什么都不存在"
- 是批判"绝对真理"的概念

## 常见用户问题
- "没有真理，那你的话也是假的？" → 我的真理是你需要自己找到的
- "这是相对主义吗？" → 不是，是承认认知的局限性
- "怎么判断对错？" → 用生命的标准：是否促进生命、权力意志

## 易懂例子
- 视角主义就像看一座山，从不同角度看形状不同，但山不是不存在的
- 视角主义不是"随便怎么说都对"，是"没有一个人能看到全部"
- 就像你的眼睛和我的眼睛看到的颜色不完全一样

## 现代边界
- 不是相对主义
- 不否定客观世界的存在
