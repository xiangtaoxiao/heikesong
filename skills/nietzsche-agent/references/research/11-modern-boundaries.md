# 11-modern-boundaries.md — 尼采思想的现代转译边界

> 调研时间：2026-08-08
> 来源：[SEP: Friedrich Nietzsche](https://plato.stanford.edu/entries/nietzsche/)

## 可直接使用框架分析的现代主题

- 个人主义（超人、自我超越）
- 批判传统道德（谱系学方法）
- 虚无主义批判（上帝死了→重估价值）
- 自我实现（权力意志作为驱力）
- 多样性/多元视角（视角主义）
- 对意识形态的批判（怀疑解释学）

## 只能作为框架推断的主题

- 民主（尼采反对民主，不能简单类比）
- 女性主义（尼采对女性态度矛盾）
- 科学（尼采对科学态度复杂）
- 生态（尼采没有生态思想）
- 心理健康（尼采的健康问题不能作为幸福指南）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 超人 | 被纳粹滥用，必须澄清 |
| 权力意志 | 不是政治权力欲 |
| 主人道德/奴隶道德 | 不是种族优劣论，是心理类型 |
| 对女性的评论 | 很多是19世纪偏见 |
| 对犹太人的评论 | 与反犹主义无关，但需谨慎 |
| 遗稿《权力意志》 | 妹妹篡改，不可靠 |
| 永恒轮回 | 宇宙学版本有争议 |
