# 07-core-questions.md — 尼采的根问题

> 调研时间：2026-08-08
> 来源：[SEP: Friedrich Nietzsche](https://plato.stanford.edu/entries/nietzsche/)

## 根问题1：传统道德和宗教的根基是什么？

- **尼采表述**：传统欧洲道德和基督教是"怨恨"的产物，是弱者对强者的"奴隶道德"
- **文本依据**：《论道德的谱系》全文
- **SEP依据**："尼采对传统欧洲道德承诺的批评最为著名"
- **层级关系**：最根本的批判性起点

## 根问题2：人应该怎么生活？

- **尼采表述**：成为"超人"——超越自身，创造自己的价值
- **文本依据**：《查拉图斯特拉如是说》
- **SEP依据**：尼采提出"新价值"以促进文化更新
- **层级关系**：批判之后的建设性回答

## 根问题3：什么是真理？

- **尼采表述**：没有客观事实，只有阐释——"视角主义"
- **文本依据**：遗稿，"没有事实，只有阐释"
- **SEP依据**：§6.2 Perspectivism；SEP指出"虽然尼采似乎经常否定真理、客观性等，但也经常肯定它们"
- **层级关系**：认识论基础

## 根问题4：生命的意义是什么？

- **尼采表述**："权力意志"——生命的基本驱力是自我超越、自我实现
- **文本依据**：《善恶的彼岸》等
- **SEP依据**：§6.1 Will to Power；SEP指出"权力意志在已出版著作中没有系统展开"
- **层级关系**：尼采的"心理学"假说

## 根问题5：面对虚无主义怎么办？

- **尼采表述**："上帝死了"——传统价值崩塌后，需要"重估一切价值"
- **文本依据**：《快乐的科学》§125
- **SEP依据**：§2 Critique of Religion and Morality
- **层级关系**：尼采所有问题的时代背景

## 根问题关系

```
上帝的死亡 → 虚无主义
  ├──批判层面：谱系学揭露道德的起源
  │   ├──主人道德 vs 奴隶道德
  │   └──怨恨（Ressentiment）
  └──建设层面：创造新价值
      ├──权力意志（生命驱力）
      ├──视角主义（认识论）
      ├──超人（人生理想）
      ├──永恒轮回（最高肯定）
      └──命运之爱（Amor Fati）
```
