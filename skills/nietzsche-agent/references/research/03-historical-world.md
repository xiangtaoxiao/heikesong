# 03-historical-world.md — 尼采的历史世界

> 调研时间：2026-08-08
> 来源：[SEP: Friedrich Nietzsche §1](https://plato.stanford.edu/entries/nietzsche/#LifeWorks)

## 时代背景
- **19世纪中后期欧洲**（1844-1900）：德国统一、工业革命、科学兴起
- **德意志帝国**：1871年统一，俾斯麦政策
- **思想界**：浪漫主义余波、科学唯物主义兴起、基督教衰落

## 生平大事年表

| 年份 | 事件 |
|------|------|
| 1844.10.15 | 生于普鲁士洛肯（Röcken），父为路德宗牧师 |
| 1849 | 父亲去世，全家迁往瑙姆堡 |
| 1864 | 入波恩大学 |
| 1865 | 转学莱比锡大学，发现叔本华 |
| 1868 | 在莱比锡结识瓦格纳 |
| 1869 | 24岁成为巴塞尔大学古典语文学教授（史上最年轻） |
| 1870 | 在普法战争中担任医疗兵 |
| 1872 | 出版《悲剧的诞生》 |
| 1876 | 与瓦格纳决裂开始 |
| 1878 | 出版《人性的，太人性的》 |
| 1879 | 因健康恶化辞去教授职位 |
| 1882 | 与Lou Salomé的友谊，求婚被拒 |
| 1883-1885 | 撰写《查拉图斯特拉如是说》 |
| 1886 | 出版《善恶的彼岸》 |
| 1887 | 出版《论道德的谱系》 |
| 1888 | 疯狂写作：偶像的黄昏、敌基督者、瞧！这个人 |
| 1889.1 | 在都灵街头崩溃，随后被送进精神病院 |
| 1897 | 母亲去世，由妹妹Elisabeth照顾 |
| 1900.8.25 | 在魏玛去世 |

## 思想影响
- 叔本华（意志哲学）
- 瓦格纳（早期影响，后决裂）
- 古希腊文化（语文学背景）
- 达尔文（进化论，但批判社会达尔文主义）
- 斯宾诺莎（被尼采称为"先驱"）
- 法国道德学家（拉罗什福科等）
