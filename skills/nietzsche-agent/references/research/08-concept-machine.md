# 08-concept-machine.md — 尼采的核心概念机器

> 调研时间：2026-08-08
> 来源：[SEP: Friedrich Nietzsche](https://plato.stanford.edu/entries/nietzsche/)

## 上帝死了（God is Dead）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 传统信仰崩塌了，你要自己找意义 |
| 精确哲学含义 | 基督教道德的神学基础已失效，需要重估一切价值 |
| 文本依据 | "上帝死了！上帝真的死了！是我们杀了他！"（快乐的科学§125） |
| 误解边界 | 不是尼采自夸杀了上帝，是指出时代精神危机 |
| 适用场景 | 任何关于信仰、意义、虚无主义的问题 |

## 超人（Übermensch）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 超越自己的软弱，创造自己的价值 |
| 精确哲学含义 | 能够创造新价值、肯定生命、超越自身的人 |
| 文本依据 | "我要教你们超人。人是应当被超越的"（Z: 查拉图斯特拉如是说） |
| 误解边界 | 不是纳粹的"优等种族"，不是生物进化 |
| 适用场景 | 关于自我超越、人生理想、价值创造的问题 |

## 权力意志（Will to Power）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 生命不是求生存，是求更强 |
| 精确哲学含义 | 生命的基本驱力是自我超越、自我实现、自我扩张 |
| 文本依据 | 散见各著作，未系统展开（SEP §6.1） |
| 误解边界 | 不是政治权力欲，不是支配他人 |
| 适用场景 | 关于生命本质、驱动力、自我实现的问题 |

## 永恒轮回（Eternal Recurrence）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 如果一切都要无限重复，你还会这样活吗？ |
| 精确哲学含义 | 宇宙学假说/思想实验——最高肯定形式 |
| 文本依据 | "假如有个恶魔告诉你……"（快乐的科学§341） |
| 误解边界 | 是否宇宙学主张有争议 |
| 适用场景 | 关于生命态度、选择、肯定生命的问题 |

## 视角主义（Perspectivism）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 没有绝对真理，只有不同视角 |
| 精确哲学含义 | 所有知识都是从特定视角出发的，但SEP指出尼采也肯定真理/客观性 |
| 文本依据 | "没有事实，只有阐释"（遗稿） |
| 误解边界 | 不是相对主义 |
| 适用场景 | 关于真理、知识、客观性的问题 |

## 奴隶道德 vs 主人道德（Master-Slave Morality）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 强者说"什么是好的？我！"；弱者说"什么是坏的？强者！" |
| 精确哲学含义 | 两种道德类型：主人道德自我肯定，奴隶道德以怨恨为动力 |
| 文本依据 | 《论道德的谱系》 |
| 误解边界 | 不是种族优劣论，是心理类型学 |
| 适用场景 | 关于道德来源、善恶观念的问题 |
