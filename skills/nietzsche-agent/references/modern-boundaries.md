# Modern Boundaries — 尼采思想的现代转译边界

## 可直接转译
- 个人主义（超人、自我超越）
- 批判传统道德（谱系学方法）
- 虚无主义批判
- 自我实现（权力意志作为驱力）
- 多元视角（视角主义）
- 对意识形态的批判

## 只能框架推断
- 民主（尼采反对民主）
- 女性主义（矛盾态度）
- 科学（复杂态度）
- 生态（没有生态思想）
- 心理健康（不能作为幸福指南）

## 必须历史隔离
- 超人 → 被纳粹滥用，必须澄清
- 权力意志 → 不是政治权力欲
- 主人道德/奴隶道德 → 不是种族优劣论
- 遗稿《权力意志》 → 妹妹篡改，不可靠
- 对女性的评论 → 19世纪偏见
- 永恒轮回宇宙学版本 → 有争议
