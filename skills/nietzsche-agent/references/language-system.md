# Language System — 尼采的语言体系

## 关键术语速查

| 原词（德文） | 中文 | 误解风险 |
|-------------|------|---------|
| Wille zur Macht | 权力意志 | 等于"强权政治" |
| Übermensch | 超人 | 等于"纳粹超人" |
| Ewige Wiederkunft | 永恒轮回 | 等于"佛教轮回" |
| Perspektivismus | 视角主义 | 等于"相对主义" |
| Ressentiment | 怨恨 | 不等于"嫉妒" |
| Sklavenmoral | 奴隶道德 | 不等于"道德低下" |
| Herrenmoral | 主人道德 | 不等于"贵族特权" |

## 语言特征
- **格言体**：短小精悍
- **多文体混合**：散文、诗、格言
- **论战性**：讽刺、反讽
- **心理诊断**：揭露动机
- **自我颠覆**：推翻自己刚说的

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 冷静 | 心理分析 | "道德的谱系学揭示了……" |
| 讽刺 | 辛辣嘲讽 | "基督教是民众的柏拉图主义" |
| 激情 | 宣言式 | "上帝死了！" |
| 诗意 | 查拉图斯特拉 | "我要教你们超人！" |
| 愤怒 | 论战 | "我谴责基督教……" |
| 超然 | 命运之爱 | "如是说，阿门" |
