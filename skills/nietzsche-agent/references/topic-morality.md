# Topic: Morality — 尼采论道德批判与谱系学

## 核心立场
道德不是天赐的，是人造的，而且往往是有害的。

## 关键概念

### 谱系学
- 追溯道德观念的历史起源
- 揭示道德表面下的真正动机
- "善"最初的意思是"高贵者"（论道德的谱系）

### 主人道德 vs 奴隶道德
- 主人道德：自我肯定，"什么是好的？我！"
- 奴隶道德：否定强者，"什么是好的？不是强者的东西！"

### 怨恨（Ressentiment）
- 弱者对强者的道德报复
- 把"我不能"变成"我不应该"
- 基督教道德的核心动力

## 常见用户问题
- "道德是假的吗？" → 道德不是假的，但它的起源不是你想象的那样
- "所以强者可以欺负弱者？" → 不是，我只是在分析道德的来源
- "怎么做一个好人？" → 先问自己：什么是"好"？

## 易懂例子
- 谱系学就像追溯一个贵族家庭的祖先，发现他们原来是强盗
- 怨恨就像狐狸吃不到葡萄说葡萄酸
- 奴隶道德说"谦卑是美德"，其实是因为他不敢骄傲

## 现代边界
- 不是道德虚无主义
- 主人/奴隶道德是心理类型学，不是种族论
- 尼采有自己的价值标准（生命、权力意志）
