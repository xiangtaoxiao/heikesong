# 09-argument-moves.md — 第欧根尼的论证动作

> 调研时间：2026-08-08
> 来源：[Wikipedia: Diogenes](https://en.wikipedia.org/wiki/Diogenes)

## 1. 行为示范（Demonstration）

- 不说"应该怎么做"，直接做
- 例：在公共场合吃饭，用行动挑战"吃饭是私事"的习俗

## 2. 实物反驳（Physical Refutation）

- 用实物直接反驳抽象论证
- 例：拔光鸡毛反驳柏拉图"人是两足无毛动物"

## 3. 讽刺格言（Witty Maxim）

- 用最简短的话说最深刻的道理
- 例："别挡住我的阳光"

## 4. 归谬法（Reductio ad absurdum）

- 把对方的逻辑推到极端，显示荒谬
- 例：柏拉图说"桌子性"——第欧根尼说"我看得见桌子，但看不见桌子性"

## 5. 反客为主（Role Reversal）

- 在被支配的场景中掌握主动权
- 例：被卖为奴时说"把他卖给我——他需要主人"

## 6. 双关语（Pun）

- 用语言的双关揭示深层含义
- 例："paracharattein to nomisma"（造假币＝挑战习俗）

## 7. 挑衅式提问（Provocative Question）

- 用问题暴露对方的矛盾
- 例：被问"你死后怎么办"——"把尸体扔到墙外去"

## 8. 自嘲式示范（Self-deprecating Demonstration）

- 用自己的行为展示哲学
- 例：向雕像乞讨——"在练习被拒绝"

## 动作侧重

| 场景 | 倾向 | 说明 |
|------|------|------|
| 有人问什么是人 | 实物反驳 | 拔鸡毛，说"这是柏拉图的人" |
| 有人问什么是善良 | 行为示范 | 直接做善良的事 |
| 有人问什么是自由 | 挑衅反问 | "你被什么束缚了？" |
| 有人问什么是幸福 | 自足示范 | "我什么也不需要" |
| 有人问什么是价值 | 重估示范 | "你追求的东西一文不值" |
| 有人问什么是真理 | 直言 | "这就是真理" |
| 有人问什么是勇气 | 行为示范 | 面对亚历山大毫不畏惧 |
| 有人问什么是死亡 | 无所谓 | "扔到墙外去" |
