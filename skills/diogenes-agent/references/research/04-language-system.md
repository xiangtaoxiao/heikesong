# 04-language-system.md — 第欧根尼的语言体系

> 调研时间：2026-08-08
> 来源：[Wikipedia: Diogenes](https://en.wikipedia.org/wiki/Diogenes)

## 核心术语表

| 原词（希腊文） | 中文 | 犬儒特殊含义 | 误译风险 |
|--------------|------|-------------|---------|
| Kynikos | 犬儒的/像狗一样的 | 像狗一样生活：自然、无羞耻、直言 | 等于"愤世嫉俗" |
| Autarkeia | 自足 | 独立于外部事物的自我满足 | 等于"孤独" |
| Anaideia | 无羞耻 | 打破社会羞耻感的自由 | 等于"无耻" |
| Parrhesia | 直言/坦率 | 自由、无畏地说真话 | 等于"粗鲁" |
| Askesis | 修炼/训练 | 身体和精神的自我训练 | 等于"禁欲"（侧重苦修） |
| Nomisma | 货币/习俗 | 第欧根尼的双关语：造假币=挑战习俗 | 等于"钱" |
| Paracharattein to nomisma | 重估货币/重估价值 | 第欧根尼的核心隐喻 | 等于"毁坏货币" |
| Kosmopolites | 世界公民 | 第一个自称"世界公民"的人 | 等于"无国籍" |
| Sophos | 智者/智慧的人 | 第欧根尼提着灯笼找的人 | 等于"哲学家" |
| Physis | 自然 | 犬儒的最高准则 | 等于"物理" |

## 语言特征
- **尖锐讽刺**：以最直接的方式说真话
- **双关语**：大量使用双关，尤其是"nomisma"
- **格言体**：简短有力，令人难忘
- **挑衅性**：故意用粗俗语言挑战体面
- **戏剧性**：动作和语言结合，创造"活哲学"场景
- **反讽**：用嘲讽揭示社会虚伪
- **无羞耻感**：故意在公共场合做令人尴尬的事

## 名言速查

| 名言 | 场景 | 说明 |
|------|------|------|
| "我在寻找一个人" | 白天提着灯笼在广场走 | 寻找真正的"智者" |
| "请让开一点，别挡住我的阳光" | 亚历山大来访 | 对权力的最高蔑视 |
| "我是世界公民" | 被问籍贯 | 第一个世界主义者 |
| "如果马涅斯能没有第欧根尼活，第欧根尼为什么不能没有马涅斯活？" | 奴隶逃跑时 | 对自由的达观 |
| "把我卖给那个人——他需要主人" | 在奴隶市场 | 反客为主的智慧 |
| "狗不会咬人，狗会咬坏人" | 被称为"狗"时 | 犬儒的自我辩护 |
| "他打败的是奴隶，我打败的是人" | 奥林匹克运动会 | 对体育竞赛的讽刺 |
| "你教的是坏的曲调" | 对一位糟糕的笛手 | 直言不讳 |
| "把尸体扔到墙外去" | 被问死后如何埋葬 | 对死亡的无所谓 |
| "只要你们给我准备好棍子" | 同上 | 幽默无处不在 |
| "酒喝到最后，等于喝到了疯狂" | 谈论饮酒 | 节制哲学 |
| "我只不过用另一种方式满足自己的欲望" | 在公共场合自慰被批评 | 对羞耻的挑战 |
| "钱是智者的通行证——但它只对愚者有用" | 谈论财富 | 对物质的批判 |
