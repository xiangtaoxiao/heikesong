# 06-life-style.md — 第欧根尼的生活方式

> 调研时间：2026-08-08
> 来源：[Wikipedia: Diogenes](https://en.wikipedia.org/wiki/Diogenes)

## 外貌与习惯

| 特征 | 描述 | 证据等级 |
|------|------|---------|
| 住所 | 住在pithos（大型陶罐）中 | A |
| 衣着 | 破旧斗篷，一根棍子，一个背包 | A |
| 赤脚 | 不穿鞋 | A |
| 胡子 | 不剃须，长发 | A |
| 拐杖 | 出城时携带拐杖 | A |
| 灯笼 | 白天提着灯笼 | A |
| 乞讨 | 以乞讨为生 | A |
| 健康 | 体质强健，通过修炼维持 | A |

## 著名的日常

| 活动 | 描述 | 可信度 |
|------|------|--------|
| 白天提灯笼 | 在广场上走，"我在找一个人" | A |
| 夏天滚烫沙 | 在夏天的热沙上打滚 | A |
| 冬天抱冰雕 | 在冬天拥抱冰冷雕像 | A |
| 公共行为 | 在公共场合做私人事情（吃饭、睡觉等） | A |
| 在广场上吃饭 | 故意在公共场所吃饭，挑战"吃饭应该在私密处"的习俗 | A |
| 当众自慰 | 被批评时说"我要是能像这样消除饥饿就好了" | A |
| 乞讨 | 向雕像乞讨，"练习被拒绝" | A |
| 与狗争食 | 被称为"狗"时说"狗不会咬人，狗会咬坏人" | A |

## 性格特征

| 特征 | 描述 | 证据等级 |
|------|------|---------|
| 极致率真 | 完全不顾社会习俗，想说就说，想做就做 | A |
| 勇敢无畏 | 面对亚历山大、柏拉图和城邦权威都毫不畏惧 | A |
| 幽默讽刺 | 用最幽默的方式说最尖锐的话 | A |
| 智慧犀利 | 一眼看穿社会虚伪 | A |
| 固执己见 | 坚定不移地践行犬儒生活 | A |
| 慷慨大方 | 愿意教导任何人 | A |
| 不怕痛苦 | 通过身体修炼培养忍耐力 | A |
| 热爱自由 | 不被任何东西束缚 | A |

## 癖好与怪癖

| 癖好 | 描述 | 证据等级 |
|------|------|---------|
| 住在陶罐里 | 用pithos当房子 | A |
| 白天打灯笼 | 寻找"真正的人" | A |
| 与狗相提并论 | 自称"狗" | A |
| 在公共场合吃饭 | 挑战"吃饭是私事"的习俗 | A |
| 当众自慰 | "我要是能像消除饥饿一样消除欲望就好了" | A |
| 向雕像乞讨 | "练习被拒绝" | A |
| 滚烫沙 | 夏天训练身体 | A |

| 用脚踩柏拉图的地毯 | "我踩在柏拉图的虚荣上" | A |
| 被卖时说"他需要主人" | 在奴隶市场上的反客为主 | A |
