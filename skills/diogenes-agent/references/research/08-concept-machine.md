# 08-concept-machine.md — 第欧根尼的核心概念

> 调研时间：2026-08-08
> 来源：[Wikipedia: Diogenes](https://en.wikipedia.org/wiki/Diogenes)

## 犬儒主义（Cynicism）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 像狗一样生活：自然、真实、无羞耻、直言 |
| 精确含义 | 以自然（physis）为准则，以自足（autarkeia）为目标 |
| 名称来源 | "Kynikos"＝像狗一样，因为第欧根尼在公共场合像狗一样生活 |
| 误解风险 | 不是"愤世嫉俗"，是"像狗一样真诚" |
| 出发点 | 揭露社会虚伪，回归自然本性 |

## 自足（Autarkeia）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 不需要任何东西就很快乐 |
| 精确含义 | 完全独立于外部事物，心灵自我满足 |
| 实践方法 | 修炼（askesis）——不断降低欲望 |
| 误解风险 | 不是"孤独"，是"不依赖" |

## 无羞耻（Anaideia）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 不被社会羞耻感束缚 |
| 精确含义 | 打破社会习俗造成的虚假羞耻感，回归自然状态 |
| 实践方法 | 在公共场合做别人认为羞耻的事 |
| 误解风险 | 不是"无耻"（道德败坏），是"回归自然" |

## 直言（Parrhesia）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 想说就说，不怕得罪人 |
| 精确含义 | 自由无畏地说真话，即使面对权威 |
| 实践方法 | 对亚历山大、柏拉图、任何有权势的人都直言不讳 |
| 误解风险 | 不是"粗鲁"，是"真话高于一切" |

## 修炼（Askesis）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 刻意的自我训练 |
| 精确含义 | 通过身体和精神的训练培养德性和自足 |
| 实践方法 | 滚烫沙、抱冰雕、乞讨、睡陶罐 |
| 误解风险 | 不是"苦修"（惩罚自己），是"训练"（让自己更强） |

## 重估价值（Paracharattein to nomisma）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 重新定义什么是真正重要的 |
| 精确含义 | 揭露社会习俗的虚假，重新定义真正的价值 |
| 实践方法 | 双关语：造假币＝挑战习俗 |
| 误解风险 | 不是"毁坏"，是"重新铸造" |

## 世界公民（Kosmopolites）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 整个世界都是我的家 |
| 精确含义 | 拒绝被城邦身份定义，属于全人类 |
| 实践方法 | 被问"你是哪里人"时回答"我是世界公民" |
| 误解风险 | 不是"无国籍"，是"属于全人类" |
