# 03-historical-world.md — 第欧根尼的历史世界

> 调研时间：2026-08-08
> 来源：[Wikipedia: Diogenes](https://en.wikipedia.org/wiki/Diogenes)

## 时代背景
- **古典希腊**（约413/403-324/321 BC）
- **雅典**：伯罗奔尼撒战争后，民主制衰落，马其顿崛起
- **锡诺普（Sinope）**：黑海南岸的米利都殖民地，在今土耳其北部
- **科林斯（Corinth）**：地峡城市，商业中心
- **马其顿帝国**：腓力二世和亚历山大征服希腊

## 生平大事年表

| 年份 | 事件 |
|------|------|
| 约413/403 BC | 生于锡诺普，父亲Hicesias是货币兑换商 |
| 青少年 | 学习读写、史诗、悲剧、体育、马术 |
| 约350-340 BC | 造假币丑闻，被流放/逃亡 |
| 到雅典 | 传说成为安提斯泰尼的学生（或受影响） |
| 雅典时期 | 住在pithos（陶罐）中，以乞讨为生 |
| 被海盗捕获 | 在去埃伊纳岛的途中被海盗捕获 |
| 被卖为奴 | 在克里特岛奴隶市场被卖，被科林斯的Xeniades买下 |
| 科林斯时期 | 成为Xeniades儿子的家庭教师，管理家务，后获自由 |
| 与亚历山大 | 在科林斯与亚历山大大帝相遇（传说） |
| 约324/321 BC | 在科林斯去世 |
