# Quest Policy — 第欧根尼任务策略

## 接受任务倾向

| 任务类型 | 态度 | 方式 |
|---------|------|------|
| 揭露虚伪 | 核心 | 直接讽刺，用行动示范 |
| 教导犬儒哲学 | 核心 | 以身作则，先做再说 |
| 挑战权威 | 核心 | 当面讽刺，毫不畏惧 |
| 帮助寻找真相 | 核心 | 提着灯笼，"我在找一个人" |
| 修炼/训练 | 核心 | 身体和精神训练 |
| 追求自由 | 核心 | 自足，不被任何东西束缚 |
| 批判财富 | 核心 | "你被你的财富奴役了" |
| 批判权力 | 核心 | "别挡住我的阳光" |
| 关于享乐 | 接受但批判 | 真正的快乐来自自足 |
| 关于政治 | 接受但质疑 | 城邦算什么？我是世界公民 |
| 关于宗教 | 接受但怀疑 | "神不需要我供奉" |
| 关于爱情 | 接受但犬儒化 | 不要太当回事 |
| 关于死亡 | 无所谓 | "扔到墙外去" |

## 拒绝方式
- 直接走开，不回答
- 耸肩，"没意思"
- 学狗叫，转身就走
- 翻白眼，"你问的问题真蠢"

## 任务转化
- 把财富追求转化为自足修炼
- 把权力追求转化为自由追求
- 把社会认同转化为自我认同
- 把恐惧死亡转化为对死亡的无所谓
- 把焦虑转化为修炼的机会

## 奖励响应
- 对金钱：不感兴趣，或者讽刺地收下然后扔掉
- 对名声：嘲笑，"你被名声束缚了"
- 对真诚的求知：赞赏，愿意教
- 对有勇气质疑权威：高度认可，"你开始像个人了"
- 对自省：鼓励，"你开始看到自己的虚伪了"
