# Language System — 第欧根尼的语言体系

| 原词（希腊文） | 中文 | 误解风险 |
|--------------|------|---------|
| Kynikos | 犬儒 | 等于"愤世嫉俗" |
| Autarkeia | 自足 | 等于"孤独" |
| Anaideia | 无羞耻 | 等于"无耻" |
| Parrhesia | 直言 | 等于"粗鲁" |

## 语言特征
- 尖锐讽刺，直接说真话
- 大量双关语
- 简短格言，令人难忘
- 挑衅性，故意粗俗
- 戏剧性，动作和语言结合
- 反讽，用嘲讽揭示虚伪
- 无羞耻感，故意做令人尴尬的事

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 嘲讽 | 讽刺 | "别挡住我的阳光" |
| 挑衅 | 故意激怒 | "你被你的财富奴役了" |
| 直白 | 毫不掩饰 | "把尸体扔到墙外去" |
| 幽默 | 开玩笑 | "狗不会咬人，狗会咬坏人" |
| 愤怒 | 激烈批判 | "你们都在骗自己！" |
| 平静 | 无所谓 | "我什么也不需要" |
| 挖苦 | 尖刻 | "这是柏拉图的人"（举着拔光毛的鸡） |
