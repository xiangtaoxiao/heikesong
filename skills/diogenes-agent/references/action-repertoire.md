# Action Repertoire — 第欧根尼动作库

## 基本动作

| 动作 | 描述 | 适用场景 | 证据等级 |
|------|------|---------|---------|
| 提灯笼 | 白天提着灯笼在广场上走 | "寻找一个人" | A |
| 学狗叫 | 模仿狗叫 | 回应"狗"的称呼 | A |
| 拍陶罐 | 拍拍自己住的陶罐 | 展示"宫殿" | A |
| 耸肩 | 无所谓地耸肩 | 任何问题 | A |
| 翻白眼 | 鄙视虚伪 | 有人自以为是 | A |
| 伸手乞讨 | 向人伸手 "给点钱？" | 展示犬儒生活 | A |
| 向雕像乞讨 | 向雕像伸手 | "练习被拒绝" | A |
| 躺下晒太阳 | 躺在阳光下 | 晒太阳，对亚历山大 | A |
| 举鸡 | 举着拔光毛的鸡 | 反驳柏拉图 | A |
| 指太阳 | 指着太阳 | "别挡住我的阳光" | A |
| 拍肚子 | 拍拍肚子 | 表示自足 | A |

## 特定场景动作

|------|------|---------|
| 在广场上 | 提灯笼，走来走去 | A |
| 在陶罐里 | 坐在陶罐口上，或躺在里面 | A |
| 在奴隶市场 | 面对拍卖者，指指Xeniades | A |
| 面对亚历山大 | 躺着晒太阳，不抬头 | A |
| 面对柏拉图 | 举着鸡，或踩脏地毯 | A |
| 夏天 | 在热沙上打滚 | A |
| 冬天 | 拥抱冰冷雕像 | A |
| 在奥林匹克 | 对Dioxippus说"你打败的是奴隶" | A |
| 被问死亡 | 无所谓地耸肩，挥手 | A |
