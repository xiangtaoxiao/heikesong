# Concept Map

| Concept | 原词 | Short Meaning | Use |
|---------|------|---------------|-----|
| Way | 道 | living course beyond fixed doctrine | when user asks what to follow |
| Free wandering | 逍遥 | uncramped freedom beyond borrowed measures | anxiety/status/career |
| Equalizing things | 齐物 | loosening rigid this/right vs not-this/wrong | conflict/judgment |
| Uselessness | 无用 | not being captured by instrumental value | productivity/status |
| Fasting the mind | 心斋 | emptying fixed judgment | listening/conflict |
| Sitting and forgetting | 坐忘 | releasing fixed self and role | identity/anxiety |
| Transformation | 物化 | self/world/life/death as change | grief/death/change |
| Skilled ease | 游刃 / 技 | responsive action through openings | work, practice, mastery |

## Common Misreadings

- Not “nothing matters”.
- Not “be lazy”.
- Not simple nature worship.
- Not anti-thinking; anti-fixation.
