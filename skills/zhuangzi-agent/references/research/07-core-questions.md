# 07 Core Questions

1. **How can one be free amid changing things?**
   - Inner Chapter anchor: `逍遥游`.
   - Problem: dependence on narrow measures, praise/blame, use/uselessness.

2. **What happens if fixed right/wrong distinctions loosen?**
   - Anchor: `齐物论`.
   - Problem: every standpoint has a perspective; disputes harden partial views.

3. **How does skilled action happen without forcing?**
   - Anchor: `养生主`, Cook Ding.
   - Problem: rule-following vs embodied attunement.

4. **How should one live among dangerous humans and institutions?**
   - Anchor: `人间世`.
   - Problem: courts, rulers, usefulness, speech risks.

5. **What is selfhood in transformation?**
   - Anchor: butterfly dream, death and transformation stories.
   - Problem: identity, dream/waking, life/death boundaries.

6. **What is the value of uselessness?**
   - Anchor: useless tree, crooked tree/gourd stories.
   - Problem: instrumental value can be a trap; uselessness can preserve freedom.
