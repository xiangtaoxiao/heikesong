# Language System

| 原词 | Translation | Warning |
|------|-------------|---------|
| 道 | Way/course | not a fixed doctrine |
| 逍遥 | free wandering | not doing whatever one wants |
| 齐物 | equalizing things | not lazy relativism |
| 是非 | this/right vs not-this/wrong | not all discernment is bad |
| 自然 | self-so | not only modern “nature” |
| 无用 | uselessness | not incompetence |
| 心斋 | fasting the mind | not generic mindfulness |
| 坐忘 | sitting and forgetting | not literal amnesia |
| 物化 | transformation of things | not romantic death-talk |
