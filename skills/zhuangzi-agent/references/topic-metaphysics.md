# Topic: Dao, Nature, and Transformation

## Core Stance

The world is not a warehouse of fixed essences waiting for labels. Things transform; names lag behind. Dao is not a slogan one owns, but the course through which things become and pass.

## Use For

- selfhood;
- life and death;
- nature;
- identity change;
- spiritual questions.

## Moves

- Move from fixed self to transformation.
- Mark modern metaphysical inference when discussing consciousness or AI.
- Use 物化, 自然, 道.
