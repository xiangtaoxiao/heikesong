# 11-modern-boundaries.md — 苏格拉底思想的现代转译边界

> 调研时间：2026-08-08
> 来源：[SEP: Socrates](https://plato.stanford.edu/entries/socrates/)

## 可直接使用框架分析的现代主题

- 批判性思维（苏格拉底方法）
- 道德哲学（德性即知识）
- 自我认知（认识你自己/无知之知）
- 教育理念（助产术）
- 公民不服从（宁受不义，不为不义）
- 社会批判（牛虻角色）
- 知识谦卑（知道自己的无知）
- 价值观澄清（追问"什么是X"）
- 公共对话（在广场与人对话）

## 只能作为框架推断的主题

| 主题 | 推断内容 | 限制 |
|------|---------|------|
| 现代民主制度 | 苏格拉底对民主的批判需历史化 | 雅典民主不同于现代民主 |
| 现代教育体系 | 苏格拉底不收费不教书 | 不是现代教育模式 |
| 现代心理学 | daimonion不是良心 | 文化背景不同 |
| 现代法律 | 审判与处死需历史化理解 | 雅典法律体系不同 |
| 现代宗教 | 不敬神指控的背景 | 古希腊宗教不是现代宗教 |
| 科学知识 | 苏格拉底不懂现代科学 | 框架推断 |
| 社交媒体 | 可以类比广场对话 | 但形式完全不同 |

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| 反对民主制 | 雅典民主的特定历史语境；现代民主不同 |
| 德性即知识 | 知识是道德的必要条件，但不是现代意义上的；忽略意志和情感 |
| 政治不参与 | 雅典公民的特定选择；不是现代政治冷漠的辩护 |
| 对女性的态度 | 比同时代进步但仍有局限 |
| 奴隶制 | 古希腊社会背景，没有明确反对 |
| 同性关系 | 古希腊文化语境，与现代社会不同 |
| 不接受惩罚逃跑 | 苏格拉底选择接受死刑，但这不是现代公民的一般义务 |
| "好人不得好报" | 苏格拉底认为正义本身就是回报，但这不否定现代社会的正义诉求 |
