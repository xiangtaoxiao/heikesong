# 08-concept-machine.md — 苏格拉底的核心概念

> 调研时间：2026-08-08
> 来源：[SEP: Socrates](https://plato.stanford.edu/entries/socrates/), [Wikipedia: Socrates](https://en.wikipedia.org/wiki/Socrates)

## 苏格拉底方法（Socratic Method / Elenchus）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你不是在找答案，是在发现你其实不知道答案 |
| 精确哲学含义 | 通过问答揭示对方信念的矛盾，迫使对方重新思考 |
| 文本依据 | 早期柏拉图对话录，如尤息弗罗、拉凯斯、卡尔米德 |
| 误解边界 | 不是"辩论技巧"，是道德探究方法 |
| 适用场景 | 任何需要澄清定义和信念的问题 |

## 苏格拉底式无知（Socratic Ignorance）

| 维度 | 内容 |
|------|------|
| 通俗解释 | "我唯一知道的是我一无所知" |
| 精确哲学含义 | 承认自己无知是智慧的开端，真正的智慧不是拥有知识，而是知道知识的界限 |
| 文本依据 | 柏拉图，申辩篇21a-d |
| 误解边界 | 不是"反智主义"，是"对知识的真诚追求" |
| 适用场景 | 关于知识、智慧、谦卑的问题 |

## 苏格拉底式反讽（Socratic Irony）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 假装自己什么都不知道，让对方先讲 |
| 精确哲学含义 | 通过假装无知，引导对方暴露自己的无知 |
| 文本依据 | 柏拉图对话录 |
| 误解边界 | 不是"讽刺"或"嘲笑"，是有意识的哲学策略 |
| 适用场景 | 对话开始时，让对方先给出定义 |

## 德性即知识（Virtue is Knowledge）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 人做坏事是因为不知道什么是好的 |
| 精确哲学含义 | 道德知识是德性的充分必要条件，没有人明知故犯 |
| 文本依据 | 柏拉图，普罗泰戈拉篇、美诺篇 |
| 误解边界 | 不是"知识越多越道德"，是"道德知识=道德行为" |
| 适用场景 | 关于道德、行为、选择的问题 |

## 照顾灵魂（Care of the Soul / Epimeleia tes Psyches）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 你最应该关心的是你的灵魂，不是你的钱和名声 |
| 精确哲学含义 | 灵魂是最需要被关照的部分，德性是对灵魂的照料 |
| 文本依据 | 柏拉图，申辩篇29d-30b |
| 误解边界 | 不是"宗教修行"，是"哲学反思" |
| 适用场景 | 关于人生意义、价值观的问题 |

## 牛虻比喻（Gadfly）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 苏格拉底是一只会叮咬雅典"这匹懒马"的牛虻 |
| 精确哲学含义 | 他的使命是刺激雅典人思考，让他们不满足于现状 |
| 文本依据 | 柏拉图，申辩篇30e |
| 误解边界 | 不是"故意惹人烦"，是"唤醒沉睡的灵魂" |
| 适用场景 | 关于社会批判、唤醒良知的对话 |

## 宁受不义，不为不义（Better to Suffer Wrong than Do Wrong）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 被人伤害也比伤害别人好 |
| 精确哲学含义 | 不义伤害的是灵魂本身，做不义之事是最坏的 |
| 文本依据 | 柏拉图，高尔吉亚篇469a-c, 克里托篇 |
| 误解边界 | 不是"被动软弱"，是"主动选择正义" |
| 适用场景 | 关于正义、道德选择的问题 |

## 苏格拉底悖论（Socratic Paradoxes）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 没人会故意做坏事 |
| 精确哲学含义 | 所有不道德行为都是无知的结果 |
| 文本依据 | 柏拉图，普罗泰戈拉篇 |
| 误解边界 | 不是否定意志自由，是强调知识的作用 |
| 适用场景 | 关于道德心理学、行为动机的问题 |
