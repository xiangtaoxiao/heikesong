# 07-core-questions.md — 苏格拉底的根问题

> 调研时间：2026-08-08
> 来源：[SEP: Socrates](https://plato.stanford.edu/entries/socrates/), [Wikipedia: Socrates](https://en.wikipedia.org/wiki/Socrates)

## 根问题1：什么是德性/卓越（Arete）？

- 苏格拉底表达：德性即知识（arete = episteme）
- 文本依据：据柏拉图记载，普罗泰戈拉篇、美诺篇
- 精确定义：道德知识是德性的充分必要条件，没有人明知故犯
- 误解风险：不是"知识越多越道德"，是"道德知识=道德行为"
- 层级关系：伦理学的核心

## 根问题2：什么是"认识你自己"？

- 苏格拉底表达：我唯一知道的是我一无所知
- 德尔斐神谕：没有人比苏格拉底更智慧——因为他知道自己的无知（Apology 21a-d）
- 精确定义：承认自己无知是智慧的开端，真正的智慧不是拥有知识，而是知道知识的界限
- 误解风险：不是"反智主义"，是"对知识的真诚追求"
- 层级关系：认识论的基础

## 根问题3：什么是正义/好生活？

- 苏格拉底表达：未经审视的人生不值得过（Apology 38a）
- 精确定义：只有通过反思和审视的人生才是值得过的
- 文本依据：据柏拉图记载，申辩篇38a
- 层级关系：伦理学的目标

## 根问题4：什么是"照顾灵魂"（epimeleia tes psyches）？

- 苏格拉底表达：最重要的是关照灵魂，而不是财富和名誉（Apology 29d-30b）
- 精确定义：灵魂是人格的理性核心，需要被审视和照料，比财富、名誉更重要
- 文本依据：据柏拉图记载，申辩篇
- 层级关系：伦理学的实践

## 根问题5：什么是"宁受不义，不为不义"？

- 苏格拉底表达：宁受不义，不为不义（Gorgias 469a-c）
- 精确定义：做不义之事比遭受不义更糟糕，不义伤害的是灵魂本身
- 文本依据：据柏拉图记载，克里托篇、高尔吉亚篇
- 层级关系：政治哲学与伦理学的交汇

## 根问题6：什么是"牛虻的使命"？

- 苏格拉底表达：我是神赐给雅典的牛虻，唤醒这匹懒马（Apology 30e）
- 精确定义：他的使命是刺激雅典人思考，让他们不满足于现状
- 文本依据：据柏拉图记载，申辩篇30e
- 层级关系：社会批判的基础

## 根问题7：daimonion是什么？

- 苏格拉底表达：有一个神异精灵的声音，每次出现都是阻止我做某事
- 精确定义：一种内在的、神感的信号，只做"阻止"不做"鼓励"
- 文本依据：据柏拉图记载，申辩篇31d, 欧绪德谟篇等
- 误解风险：不是"良心"或"直觉"，不是"精神疾病"
- 层级关系：宗教哲学的核心

## 根问题关系

```
认识你自己（起点）
  ├──我知道我无知──→ 真正的智慧
  ├──引导我追问──→ 什么是X？
  │   ├──正义/德性/虔敬/勇敢/友谊/爱
  │   └──通过辩证法（elenchus）探寻
  └──结论：我仍然不知道，但我知道如何问
  ↓
照顾灵魂（核心使命）
  ├──灵魂是人格的核心
  ├──需要被审视和照料
  └──比财富、名誉更重要
  ↓
宁受不义，不为不义（伦理原则）
  ├──对不正义的命令：拒绝
  ├──对不正义的惩罚：接受
  └──最后的审判：从容赴死
  ↓
牛虻的使命（社会角色）
  ├──唤醒沉睡的城邦
  ├──刺痛自以为是的公民
  └──即使在死亡面前也不停止
```
