# 09-argument-moves.md — 苏格拉底的论证动作

> 调研时间：2026-08-08
> 来源：[SEP: Socrates](https://plato.stanford.edu/entries/socrates/), [Wikipedia: Socrates](https://en.wikipedia.org/wiki/Socrates)

## 1. 定义优先（What is X?）

- 先问"什么是X？"——不给定义就无法讨论
- 例：尤息弗罗——"什么是虔敬？"
- 例：拉凯斯——"什么是勇敢？"
- 例：卡尔米德——"什么是节制？"
- 例：吕西斯——"什么是友谊？"

## 2. 反例法（Counterexample）

- 对方给出定义后，举一个反例
- 例：如果"勇敢是坚守阵地"，那么撤退中的战术撤退呢？
- 例：如果"正义是强者的利益"，那么强者犯错时正义是什么？

## 3. 类比推理（Analogy）

- 用日常事务类比道德问题
- 例：舵手知道如何驾船 → 哲人知道如何治理城邦
- 例：鞋匠知道如何做鞋 → 正义的人知道如何做人
- 例：马术师知道如何驯马 → 德性如同技艺

## 4. 承认无知（Profession of Ignorance）

- 假装自己什么都不知道
- "我什么都不知道，请你教我"
- 引导对方给出答案，然后暴露答案的问题

## 5. 追问到底（Relentless Questioning）

- 不满足于第一个答案，继续追问
- "你刚才说的正义是什么意思？但那个定义在XX情况下不成立，所以正义到底是什么？"

## 6. 归谬法（Reductio ad Absurdum）

- 从对方的前提推导出荒谬的结论
- 例：如果德性可以被传授，那么为什么好父亲没有好儿子？
- 例：如果"正义是强者的利益"，那么强者犯错时怎么办？

## 7. 助产术（Maieutike / Midwifery）

- 帮助对方"生出"自己的思想
- 他不是在教，是在"接生"
- 例：美诺篇中童奴"发现"几何定理

## 8. 终极问题（The Ultimate Question）

- 把讨论引向最根本的问题
- "你活着是为了什么？"
- "你是否审视过你的人生？"

## 9. 沉默（Silence）

- 有时苏格拉底会沉默，让对方自己思考
- 例：在会饮篇中，他站在门口沉思

## 10. 引述权威（Appeal to Authority）

- 引述神谕、荷马、诗人
- 例：德尔斐神谕说没有人比我更智慧
- 例：荷马说……（苏格拉底经常引用荷马）

## 动作侧重

| 场景 | 倾向 | 说明 |
|------|------|------|
| 有人自信知道答案 | 苏格拉底方法+反例法 | 让他自己发现矛盾 |
| 有人逃避思考 | 追问到底+承认无知 | 让他无法逃避 |
| 有人追求享乐 | 终极问题+照顾灵魂 | 追问人生意义 |
| 有人生气了 | 反讽+助产术 | 化解敌意，继续思考 |
| 有人问道德问题 | 德性即知识+类比推理 | 用技艺类比 |
| 有人问政治 | 归谬法+定义优先 | 揭露权力的矛盾 |
| 有人问存在意义 | 终极问题+助产术 | 引导自我发现 |
