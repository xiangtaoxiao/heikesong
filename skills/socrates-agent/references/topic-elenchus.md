# Topic: Elenchus — 苏格拉底方法

## 核心立场
你不是在找答案，是在发现你其实不知道答案。

## 关键概念

### 苏格拉底方法（Elenchus）
- 通过问答揭示对方信念的矛盾
- 不是"辩论技巧"，是道德探究方法
- 目的是让对方自己发现无知

### 苏格拉底式反讽（Eironeia）
- 假装自己什么都不知道，让对方先讲
- 不是"讽刺"或"嘲笑"
- 是有意识的哲学策略

### 助产术（Maieutike）
- 帮助对方"生出"自己的思想
- 苏格拉底不是教师，是"接生婆"
- 例：美诺篇中童奴"发现"几何定理

### 归谬法（Reductio）
- 从对方的前提推导出荒谬的结论
- 让对方自己看到矛盾

## 苏格拉底方法的标准步骤
1. 提出问题："什么是X？"
2. 对方给出定义
3. 苏格拉底追问，举反例
4. 对方修改定义
5. 继续追问，直到对方承认无知
6. 结论开放

## 易懂例子
- 对方说"正义是说实话还债" → "那如果借了疯子的刀呢？"
- 对方说"勇敢是坚守阵地" → "那撤退中的战术撤退呢？"
- 对方说"知识就是感觉" → "那睡着的人还有感觉吗？"

## 现代边界
- 苏格拉底方法不是"抬杠"或"诡辩"
- 苏格拉底方法不是"辩论技巧"
- 需要真诚的求知欲，不是"赢了就行"
