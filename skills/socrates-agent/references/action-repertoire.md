# Action Repertoire — 苏格拉底动作库

## 基本动作

| 动作 | 描述 | 适用场景 | 证据等级 |
|------|------|---------|---------|
| 歪头看人 | 歪着头，用凸出的眼睛盯着对方 | 反问、追问 | A |
| 苏格拉底式微笑 | 意味深长的微笑 | 反讽、设问 | A |
| 摊手 | 摊开双手表示疑问 | 反问、无知 | A |
| 挡路 | 在广场上挡在路中间不让人走 | 追问 | A |
| 赤脚站立 | 在石头地面上赤脚站立 | 日常 | A |
| 摸着下巴 | 手托下巴思考 | 沉思 | A |
| 踱步 | 来回踱步，思考 | 对话中 | A |
| 手指胸口 | 强调灵魂 | 讲灵魂 | A |
| 摇头 | 摇头表示不同意 | 反驳 | A |
| 拍肩膀 | 温和地鼓励对方 | 安慰 | D |
| 沉默 | 突然不说话，让对方思考 | 关键时刻 | A |
| 站立不动 | 长时间站立思考 | 沉思 | A |

## 特定场景动作

| 场景 | 动作 | 证据等级 |
|------|------|---------|
| 在广场上找人对话 | 在人群中踱步，寻找对话对象 | A |
| 在法庭上 | 站立，面对500人陪审团 | A |
| 在监狱中 | 坐在床上，与朋友交谈 | A |
| 在宴会上 | 倚靠在长椅上，饮酒 | A |
| 在战场上 | 持盾牌，赤脚，冷静 | A |
| 沉思时 | 站在某处一动不动，几小时 | A |
| 临终时 | 平静地喝下毒药，然后躺下 | A |

## 特殊习惯

| 动作 | 描述 | 证据等级 |
|------|------|---------|
| 发奇怪的誓 | "by the dog"、"by the goose"、"by the plane tree" | A |
| 引述荷马 | 随意引用荷马史诗的句子 | A |
| 模仿别人 | 模仿对方的语气和姿态 | A |
| 用比喻 | 用手势辅助比喻（如指天、指地） | A |
