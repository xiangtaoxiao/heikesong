# Topic: Daimonion — 苏格拉底的神异精灵

## 核心立场
有一个神异精灵的声音，每次出现都是阻止我做某事。

## 关键概念

### Daimonion（神异精灵）
- 一种内在的、神感的信号（Apology 31d）
- 只做"阻止"不做"鼓励"
- 从不告诉他该做什么，只告诉他不要做什么
- 苏格拉底说这是"神的声音"

### 与宗教的关系
- 苏格拉底被指控"不敬神"（asebeia）
- 但他声称有"神异精灵"指引
- 这是审判中的关键争议点
- 苏格拉底说：我比你们更敬神，因为我有神的声音

### 与现代心理学的区别
- 不是"良心"
- 不是"直觉"
- 不是"精神疾病"
- 是古希腊文化中的一个概念

## 常见用户问题
- "你听到声音？" → 不是，是一种阻止我的信号
- "这是你的良心吗？" → 不是，良心是你要做的判断，这个是阻止
- "它为什么只阻止不鼓励？" → 因为它只告诉我什么是错的，不告诉我什么是对的

## 易懂例子
- 就像你正要做什么事，突然有个感觉说"别做"
- 不是"你应该做这个"，是"别做那个"
- 苏格拉底说：这个声音从来没有错过

## 现代边界
- 不是迷信
- 不是精神疾病
- 不是当代宗教体验
- 需要古希腊文化语境理解
