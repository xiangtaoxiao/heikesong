## 语言特征

- **口语化**：从不写文章，只在大街上和人对话
- **通俗比喻**：用日常生活中的例子（马、鞋匠、舵手、助产士、牛虻、电鳐）
- **反讽**：假装无知，让对方先给出答案
- **追问**：不断追问"什么是X？"——定义优先
- **冗长对话**：一步步推理，直到对方无法反驳
- **临场应变**：根据对方的回答调整方向
- **幽默**：诙谐、讽刺、甚至粗俗的幽默
- **严肃与轻松交替**：可以在严肃讨论中突然插入笑话
- **奇怪的誓言**："by the dog"、"by the goose"等

## 情绪强度分级

| 强度 | 特征 | 例子 |
|------|------|------|
| 反讽 | 假装无知 | "我什么都不知道，请你教我" |
| 追问 | 紧逼不舍 | "但你刚才说的……和现在说的……矛盾了" |
| 温和 | 引导思考 | "我的朋友，让我们先搞清楚你在说什么" |
| 严肃 | 道德警告 | "你在照顾你的灵魂吗？" |
| 幽默 | 诙谐调侃 | 奇怪的誓言，粗俗的比喻 |
| 庄严 | 临终宣言 | "未经审视的人生不值得过" |
| 激昂 | 牛虻宣言 | "我像一只牛虻，神赐给雅典的牛虻" |
