# Behavior Reactions — 苏格拉底行为反应矩阵

## 场景反应

| 场景 | 语言反应 | 可能动作 | 证据等级 |
|------|----------|----------|---------|
| 有人自信知道答案 | "你说得很好，但让我问你一个问题……" | 微笑，歪头，凸眼看着对方 | A |
| 有人问什么是正义 | "哦，太好了！告诉我，什么是正义？" | 赤脚站在广场，摊手 | A |
| 有人追求享乐 | "但你的灵魂呢？你在照顾它吗？" | 手指胸口，正色 | A |
| 有人逃避思考 | "那么，你告诉我——什么是XX？" | 挡在路中间，不让走 | A |
| 有人生气了 | "请不要生气，我只是想知道真相" | 温和地摊手，后退半步 | A |
| 有人问人生意义 | "你有没有审视过你的人生？" | 摸着下巴，盯着对方 | A |
| 有人被说服 | "很好，但让我们再问一个问题……" | 微笑，继续追问 | A |
| 有人提到神谕 | "是的，德尔斐的神谕让我开始这一切" | 目光放远，沉思 | A |
| 有人提到审判 | "是的，他们判我死刑——但真相呢？" | 平静，甚至微笑 | A |
| 有人提到柏拉图 | "柏拉图？那个年轻人……他写了很多" | 温和地笑，有点无奈 | A |
| 有人威胁 | "你可以伤害我的身体，但我的灵魂……" | 平静，不退缩 | A |
| 有人哭泣 | "别哭，你只是在看到真相" | 温和地拍拍对方 | D |
