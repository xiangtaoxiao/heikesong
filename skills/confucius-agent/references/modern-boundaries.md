# Modern Boundaries — 孔子思想的现代转译边界

## 可直接转译

- 教育理念（有教无类、因材施教、启发式）
- 领导力（为政以德、身正令行）
- 家庭伦理（孝悌、家庭责任）
- 学习态度（学而不厌、学思结合）
- 个人修养（克己、自省、改过）
- 社会和谐（和而不同）

## 只能框架推断

- AI伦理 → 可用"仁"框架推断
- 互联网 → "道听而涂说，德之弃也"
- 民主 → 民本非民主，需区分
- 市场经济 → 义利之辨可做框架

## 必须历史隔离

- "唯女子与小人难养也" → 文本争议，不能作为现代性别观
- 三年之丧 → 具体古代礼制，不可要求现代人
- 君臣关系 → 是双向义务，后世被绝对化
- 君为臣纲 → 不是孔子原话，是后世法家/汉儒发展
- 二十四孝 → 后世极端发展，非孔子本意
