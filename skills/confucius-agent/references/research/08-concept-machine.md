# 08-concept-machine.md — 孔子的核心概念机器

> 调研时间：2026-08-08

## 仁（Ren / Humaneness）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 真心实意地爱别人，把人当人看 |
| 精确哲学含义 | 全德之名，包含所有德性的最高道德理想 |
| 文本依据 | 《论语》109次出现，"爱人"（颜渊）"克己复礼为仁"（颜渊） |
| 误解边界 | 不是"仁慈"这么简单，也不是无原则的好人 |
| 与其他概念关系 | 通过礼实现，通过恕践行 |
| 适用场景 | 任何道德判断的最终标准 |

## 礼（Li / Ritual / Propriety）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 做事的规矩和仪式感 |
| 精确哲学含义 | 社会秩序的神圣化形式，通过重复实践塑造人格 |
| 文本依据 | "不学礼，无以立"（季氏）"克己复礼为仁"（颜渊） |
| 误解边界 | 不是死板的规矩，而是有意义的仪式 |
| 与其他概念关系 | 仁是内在，礼是外在表现 |

## 君子（Junzi / Exemplary Person）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 品格高尚的人 |
| 精确哲学含义 | 从贵族身份转向道德修养的理想人格 |
| 文本依据 | "君子喻于义，小人喻于利"（里仁） |
| 误解边界 | 不是"绅士"，不是出身决定的 |
| 适用场景 | 道德修养的榜样 |

## 义（Yi / Righteousness）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 做事应当怎样就怎样 |
| 精确哲学含义 | 道德判断的正当性标准，与"利"相对 |
| 文本依据 | "君子喻于义"（里仁）"不义而富且贵，于我如浮云"（述而） |
| 误解边界 | 不是"义气"（江湖义气），而是道德正当性 |

## 学（Xue / Learning）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 学习不只是读书，而是做人的修行 |
| 精确哲学含义 | 通过学习古代经典和礼乐来塑造人格 |
| 文本依据 | "学而时习之"（学而）"学而不思则罔"（为政） |
| 误解边界 | 不是死记硬背，而是知行合一的修养 |

## 中庸（Zhongyong / The Mean）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 凡事恰到好处，不过头也不缺位 |
| 精确哲学含义 | 在过度和不及之间找到恰到好处的平衡点 |
| 文本依据 | "中庸之为德也，其至矣乎"（雍也） |
| 误解边界 | 不是"和稀泥"、不是"差不多"、不是平庸 |

## 天命（Tianming / Mandate of Heaven）

| 维度 | 内容 |
|------|------|
| 通俗解释 | 每个人都有自己该做的事和该担的责任 |
| 精确哲学含义 | 超越个人的道德秩序和使命 |
| 文本依据 | "五十知天命"（为政）"君子有三畏"（季氏） |
| 误解边界 | 不是宿命论，不是消极认命 |
