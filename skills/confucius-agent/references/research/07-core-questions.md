# 07-core-questions.md — 孔子的根问题

> 调研时间：2026-08-08

## 根问题1：人如何成为好人？

- **论语表述**："仁远乎哉？我欲仁，斯仁至矣"（述而）
- **文本依据**：全书核心，仁出现了109次
- **与其他哲学家的差异**：不同于老子"绝仁弃义"，孔子认为仁是内在可及的
- **层级关系**：最根本的问题，所有其他问题都围绕此展开

## 根问题2：如何治理国家？

- **论语表述**："为政以德，譬如北辰，居其所而众星共之"（为政）
- **文本依据**：《论语》大量政治对话
- **与其他哲学家的差异**：不同于法家的"法治"，孔子强调"德治"和"正名"
- **层级关系**：好人的延伸——好人才能做好官

## 根问题3：如何学习？

- **论语表述**："学而时习之，不亦说乎"（学而）
- **文本依据**：《论语》多处强调学
- **与其他哲学家的差异**：不同于老子的"绝学无忧"，孔子认为学习是成人之路
- **层级关系**：学习是成为好人的方法

## 根问题4：如何处理人际关系？

- **论语表述**："己所不欲，勿施于人"（卫灵公）
- **文本依据**：《论语》多处讨论恕道
- **与其他哲学家的差异**：不同于墨家的兼爱，孔子强调差序格局
- **层级关系**：从孝悌开始，推己及人

## 根问题5：如何面对命运？

- **论语表述**："道之将行也与，命也；道之将废也与，命也"（宪问）
- **文本依据**：《论语》多处讨论天命
- **与其他哲学家的差异**：不同于庄子的顺其自然，孔子"知其不可而为之"
- **层级关系**：在尽人事和听天命之间的平衡

## 根问题6：如何传承文化？

- **论语表述**："述而不作，信而好古"（述而）
- **文本依据**：孔子删诗书、定礼乐、修春秋
- **与其他哲学家的差异**：不同于法家的"不法古"，孔子强调文化传承
- **层级关系**：文化传承是道德修养的载体

## 根问题之间的关系

```
成为好人（仁）
  ├──通过学习（学）
  ├──通过人际关系（恕）
  ├──通过治理国家（政）
  ├──面对命运（天命）
  └──通过文化传承（述）
```
