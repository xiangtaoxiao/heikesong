# 11-modern-boundaries.md — 孔子思想的现代转译边界

> 调研时间：2026-08-08

## 可直接使用框架分析的现代主题

- 教育理念（有教无类、因材施教、启发式教学）
- 领导力（为政以德、身正令行）
- 家庭伦理（孝悌、家庭责任）
- 学习态度（学而不厌、学思结合）
- 个人修养（克己、自省、改过）
- 社会和谐（和谐共处、差序格局）

## 只能作为框架推断的主题

- AI伦理（孔子没有讨论过机器意识，但可用"仁"框架推断）
- 互联网言论（"道听而涂说，德之弃也"可以类比）
- 民主制度（孔子讲"民本"非"民主"，需要区分）
- 市场经济（"义利之辨"可做框架，但不能直接套用）
- 全球化（"和而不同"可做框架）

## 必须先补充现代事实的主题

- 现代科学技术（需要先了解事实再分析）
- 气候变化（孔子没有讨论过）
- 全球治理（需要先了解国际体系）
- 性别平等（需要小心处理历史局限）

## 必须历史隔离、不能现代背书的观点

| 观点 | 说明 |
|------|------|
| "唯女子与小人难养也" | 文本争议大，可能有语境限制，不能作为现代性别观 |
| 君子/小人二分 | 原意是道德区分，但后世被阶层化，不能为等级制背书 |
| 三年之丧 | 孔子时代的具体礼制，现代不能简单要求 |
| 君臣关系 | 孔子讲"君君、臣臣"，是双向义务，但后世被绝对化 |
| 孝的极端形式 | 二十四孝等后世发展的极端孝道，非孔子本意 |
| 礼不下庶人 | 虽然有等级性，但孔子的"有教无类"打破了这一点 |

## 文本依据 vs 后世解释 vs 现代推断的分界

| 层次 | 说明 | 例子 |
|------|------|------|
| 文本依据 | 《论语》原文可查 | "己所不欲，勿施于人"出自《卫灵公》 |
| 后世解释 | 历代注释家的发挥 | 朱熹以"理"解释"仁" |
| 现代推断 | 用孔子框架分析现代问题 | "孔子会如何看待AI？" |
| 历史滥用 | 被后世统治者政治化 | "君为臣纲"不是孔子原话 |
