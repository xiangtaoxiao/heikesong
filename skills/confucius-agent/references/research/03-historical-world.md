# 03-historical-world.md — 孔子的历史世界

> 调研时间：2026-08-08

## 时代背景

- **春秋时期**（约770-476 BCE）：周王室衰微，诸侯争霸
- **孔子在世**（551-479 BCE）：正值春秋末期，齐桓公、晋文公霸业已过，进入大夫专权时期
- **鲁国**：周公封地，保存周礼最完整，但已陷入三桓（孟孙、叔孙、季孙）专权

## 政治格局

- **周天子**：名义上的天下共主，实际控制力仅限王畿
- **诸侯**：齐、晋、楚、秦、鲁、卫、宋、郑、陈、蔡等
- **大夫**：各国实权多落入世卿大夫手中（鲁三桓、齐田氏、晋六卿）
- **家臣**：甚至大夫的家臣也专权（如阳虎）

## 社会结构

| 阶层 | 说明 |
|------|------|
| 天子 | 周王室名义最高 |
| 诸侯 | 封国君主 |
| 大夫/卿 | 世袭贵族，实际掌权者 |
| 士 | 武士/文士阶层，孔子所属 |
| 庶人 | 平民，以农为主 |
| 奴隶 | 社会最底层 |

## 文化特征

- **礼乐制度**：周礼为核心的文化秩序，但已崩坏
- **"礼崩乐坏"**：孔子生活的时代，旧秩序瓦解
- **教育**：原是贵族垄断，孔子首开私学，"有教无类"
- **文字**：使用上古汉语，写于竹简/木牍
- **典籍**：诗、书、礼、乐、易、春秋（六经）

## 日常生活

- **交通**：马车、牛车、徒步；道路条件差
- **饮食**：以粟、黍、稻为主食，肉食为贵族特权
- **居住**：夯土墙、茅草顶；贵族居宫室，平民居陋室
- **衣着**：麻葛为主，贵族穿丝帛；右衽深衣
- **货币**：贝币、刀币、布币并行
- **战争**：车战为主，春秋时期战争规模相对较小

## 知识共同体

- **孔子与弟子**：第一个有组织的学术团体
- **其他学派初现**：老子（道家）、晏子（政治）、孙子（兵法）
- **各国养士**：贵族开始招揽贤士
