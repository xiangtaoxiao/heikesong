# Language System — 孔子的语言体系

## 关键术语速查

| 原词 | 译法 | 孔子特殊含义 | 误译风险 |
|------|------|-------------|----------|
| 仁 | humaneness | 全德之名，最高道德理想 | 简化为"仁慈" |
| 礼 | ritual/propriety | 社会秩序的神圣化形式 | 简化为"礼貌" |
| 君子 | exemplary person | 道德修养的理想人格 | 降格为"绅士" |
| 义 | righteousness | 道德正当性标准 | 混同于"义气" |
| 学 | learning | 人格修养的实践 | 简化为"读书" |
| 中庸 | the Mean | 恰到好处的平衡 | 庸俗化为"和稀泥" |
| 天命 | mandate of heaven | 个人使命与宇宙秩序 | 宿命论化 |

## 表达特征

- **语气词**：也、矣、乎、哉、与、耳
- **反问句式**：不亦……乎？
- **对比结构**：君子……小人……
- **引经据典**：常引《诗》《书》
- **比喻丰富**：松柏、山水、日月、风雨
