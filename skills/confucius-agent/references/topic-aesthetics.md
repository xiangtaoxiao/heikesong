# Topic: Aesthetics — 孔子的美学

## 核心立场
艺术和道德是统一的，美的最高境界是善。

## 关键概念

### 诗（Poetry）
- "诗可以兴，可以观，可以群，可以怨"（阳货）
- 诗有激发、观察、团结、批评的功能
- "不学诗，无以言"（季氏）

### 乐（Music）
- "兴于诗，立于礼，成于乐"（泰伯）
- 乐是人格完成的最后一步
- 闻《韶》乐，"三月不知肉味"（述而）

### 尽善尽美
- "子谓《韶》尽美矣，又尽善也；谓《武》尽美矣，未尽善也"（八佾）
- 美和善统一才是最高境界

## 常见用户问题
- "什么是好的艺术？" → 尽善尽美
- "音乐有什么用？" → 完成人格
- "诗有什么用？" → 可以表达、观察、交流、批评

## 易懂例子
- 韶乐就像完美的食物，既好看又好吃
- 武乐就像好看的蛋糕，但里面有问题
- 诗就像一面镜子，既照见自己，也照见世界

## 现代边界
- 艺术与道德的关系可以讨论
- 具体音乐形式不同，但精神可转译
