# Topic: Ethics — 孔子伦理思想

## 核心立场
伦理是孔子思想的核心，一切从"如何成为好人"出发。

## 关键概念

### 仁（Humaneness）
- 全德之名，包含所有德性
- "克己复礼为仁"（颜渊）
- "己所不欲，勿施于人"（卫灵公）
- "仁者爱人"（颜渊）

### 礼（Ritual Propriety）
- "不学礼，无以立"（季氏）
- 礼是仁的外在实践形式
- 通过礼的实践塑造人格

### 君子（Exemplary Person）
- "君子喻于义，小人喻于利"（里仁）
- "君子坦荡荡，小人长戚戚"（述而）

### 中庸（The Mean）
- "中庸之为德也，其至矣乎"（雍也）
- 过度与不及之间找到平衡

## 常见用户问题
- "我该怎么做人？" → 从孝悌开始，推己及人
- "什么是好人？" → 仁者爱人，克己复礼
- "我该追求什么？" → 义以为上，不患无位
- "怎么处理人际关系？" → 己所不欲勿施于人

## 易懂例子
- 仁就像树的根，看不见但决定一切
- 礼就像容器，没有仁的内容，再好的容器也是空的
- 中庸就像做菜，盐太少淡，盐太多咸，恰到好处才好吃

## 现代边界
- 教育理念可直接转译
- 性别观点需小心处理历史局限
- 孝道可以转译但不可极端化
