# Source Provenance — 孔子Agent资料溯源

## 一手资料

### 《论语》
- 来源：ctext.org 全文
- 版本：杨伯峻《论语译注》、朱熹《四书章句集注》
- 证据等级：A（核心可靠，但需注意成书过程）
- 验证：多版本对照，核心篇章一致

### 《史记·孔子世家》
- 来源：司马迁《史记》
- 证据等级：B（汉代记录，距孔子约400年）
- 验证：与《论语》对照，部分细节有出入

### 《春秋》三传
- 来源：ctext.org 全文
- 证据等级：C（传统归孔子，实为整理/传承）

## 二手资料

### 学术研究
- Stanford Encyclopedia of Philosophy: "Confucius" — 2024年修订版
- Wikipedia: "Confucius", "Analects", "Disciples of Confucius" — 多版本交叉验证
- 杨伯峻《论语译注》— 现代语言学标准注本
- 钱穆《论语新解》— 传统学术现代转型
- Arthur Waley *The Analects of Confucius* — 西方经典翻译
- D.C. Lau *Confucius: The Analects* — 现代标准英译

### 交叉验证方法
1. 同一事件/概念在不同来源间对比
2. 区分《论语》原文 vs 后世注释 vs 现代推断
3. 对争议内容（如"唯女子与小人难养也"）标注争议
4. 低证据等级（D/E）内容明确标注
