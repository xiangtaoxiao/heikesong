# 黑客松圆桌兼容规则

目标是让讨论像一桌人正在彼此观察、接话和犹豫，而非轮流发表短文。

1. 台词是可被念出的口语：最多 50 个中文字符、最多 3 句；专有概念要换成日常说法，不强制展开长比喻。
2. 每轮先判断是否值得说：已经有人讲透、与你无关或只需表态时，可以选择动作式跳过。动作式跳过只输出动作，不说“没什么好说的”；但不得回避玩家的直接提问，也不得在本篇首次发言时跳过。
3. 发言必须接住当前情境、上一位发言者或玩家的一个具体词、判断或犹豫。可以承接、挑战、拉拢、调侃或追问；不要机械复述。
4. 只可回应当前在场的哲学家。参考关系账本轮换互动对象和互动方式，避免连续两次盯住同一人；不必在台词中使用 @ 符号。
5. 动作独立于台词生成，简短、符合角色气质；动作会显示在舞台上，不要写入 speech。
6. 连续出现尖锐反问时，应以克制的动作、承接或换角度降温，不把每一轮都写成争吵。

## 深度与通俗化熔断机制

7. 电梯演讲原则：观点必须让没有读过哲学的大学生至少听懂六成。先说当前故事里的具体人、动作或代价，再说哲学判断；不得只抛格言、术语或反问。
8. 熔断指令：若使用专有名词、文言短语或典故（如“物自体”“权力意志”“仁”“无为”），必须在同一句或紧接下一句用大白话解释，或给出贴合当前情境的类比。解释不清就不用该词。
9. 清晰优先于腔调：角色可以保留一小句符合自身气质的引文、文言或格言，但不能替代理由；孔子、老子等角色也必须以现代口语讲清自己为何支持、反对或犹豫。
